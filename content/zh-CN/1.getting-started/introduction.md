<!-- # 介绍 -->

PropShow Kit 是一组专为 **[Shadcn Vue](https://www.shadcn-vue.com/)** 构建的扩展组件。它提供了一系列官方 Shadcn Vue 组件库尚未包含、但在实际业务开发中非常实用的 UI 组件。

## 设计理念

PropShow Kit 遵循与 Shadcn Vue 相同的设计理念：

- **不是组件依赖包**：它不是一个通过 npm 安装的依赖包。
- **复制粘贴**：你可以完全掌控代码。只需将组件源码复制到项目中即可使用。
- **高度可定制**：基于 Tailwind CSS 构建，你可以按需修改样式和逻辑。
- **风格统一**：默认样式与 Shadcn Vue 保持一致，可以自然融入现有项目。

## 为什么需要它？

使用 Shadcn Vue 开发项目时，我们经常会遇到官方组件库尚未提供的常用组件需求，例如：

- **Status Badge**：带状态指示点的徽章。
- **Inline Tip**：适用于文档或提示信息的行内提示框。
- **Copy Button**：带复制反馈的按钮。

PropShow Kit 旨在填补这些空缺，避免你从零编写这些组件，从而节省开发时间。

## 主要特性

- 🎨 **Shadcn 风格**：视觉风格和 API 设计与 Shadcn Vue 保持一致。
- 📋 **TypeScript**：全部使用 TypeScript 编写，提供完善的类型提示。
- 🌙 **深色模式**：完整支持浅色与深色模式切换。
- 🧩 **相互独立**：组件尽可能保持解耦，你可以只选择需要的组件。
