<!-- # 快速开始 -->

本指南将演示如何将一个组件快速集成到项目中。

## 第一步：选择组件

浏览左侧的组件列表，找到适合需求的组件。例如，我们选择 **[Copy](../components/copy)** 组件。

## 第二步：检查依赖

组件文档页的顶部或说明中通常会标明该组件是否依赖其他 Shadcn Vue 组件。

`Copy` 组件依赖：

- `Button` 组件
- `Tooltip` 组件
- `@lucide/vue` 图标
- `@vueuse/core`（用于剪贴板功能）

请确保项目中已经安装这些依赖：

```bash
npx shadcn-vue@latest add button tooltip
npm install @vueuse/core
```

## 第三步：复制代码

点击组件预览下方的 **Code** 标签页，即可查看组件源码。

源码通常包括：

- 组件文件，例如 `Copy.vue`
- 样式变体文件，例如使用 `cva` 时的 `index.ts`

将这些文件复制到项目中。建议保持相同的目录结构，例如 `components/prop-ui/copy/`。

## 第四步：使用组件

现在可以在应用中使用该组件：

```vue
<script setup lang="ts">
import { Copy } from '@/components/prop-ui/copy'
</script>

<template>
  <div class="p-4">
    <Copy content="Hello, PropShow Kit!" />
  </div>
</template>
```

就是这么简单。你可以根据需要修改组件代码，让它完全适配项目需求。
