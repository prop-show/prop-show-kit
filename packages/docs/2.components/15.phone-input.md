# Phone Input

> An international phone field with a country calling code. The value is E.164. Parsing comes from [libphonenumber-js](https://gitlab.com/catamphetamine/libphonenumber-js).

::phone-input-preview
::

## Install

:registry-install{url="/r/phone-input.json"}

The install also adds the `libphonenumber-js` package. Country names use `Intl.DisplayNames`, and the flag is the regional-indicator emoji for the ISO code.

## Usage

```vue
<script setup lang="ts">
import { ref } from "vue";
import { PhoneInput } from "@/components/phone-input";

const phone = ref("");
</script>

<template>
  <PhoneInput v-model="phone" label="Mobile" default-country="US" class="max-w-sm" />
</template>
```

`v-model` is an E.164 string such as `+12015550123`. An incomplete number is still emitted, for example `+1415`, so the field can stay controlled while someone is typing. `valid` is not a second model. After blur, a non-empty invalid number sets `aria-invalid` and shows `invalidMessage`.

Paste `+44 20 7946 0958` or `0044…` to switch the country from the number itself. Choosing a country from the list reinterprets the digits already in the field.

Set `name` when the form should submit the E.164 value. The visible input stays unnamed so the browser does not also submit the national formatting. Read `phone` from `v-model` when you submit with JavaScript.

Limit the list with `countries`, and pin a few with `priorityCountries`. The default pins are US, GB, CA, and AU.

## Validation

The default `libphonenumber-js` metadata checks length against the numbering plan. It does not check the finer digit patterns in the full metadata set. Pass `invalid` when your server rejects the number. Set `validate` to `false` to keep the message off and use your own error.

## Accessibility

The country control is a button named with the country and calling code. The menu search is a combobox: type to filter, Up and Down to move, Enter to choose, Escape to close. The number field uses `inputmode="tel"`. With no visible `label`, it falls back to `phoneLabel` (“Phone number”). The error text is referenced by `aria-describedby`.

## Props

| Name              | Type                      | Default                       | Description                                      |
| :---------------- | :------------------------ | :---------------------------- | :----------------------------------------------- |
| modelValue        | `string`                  | `""`                          | E.164 value (`v-model`)                          |
| defaultValue      | `string`                  | —                             | Initial E.164 value when uncontrolled            |
| defaultCountry    | `CountryCode`             | `US`                          | Country used until a number picks another one    |
| label             | `string`                  | —                             | Visible label                                    |
| placeholder       | `string`                  | —                             | National-number placeholder                      |
| autocomplete      | `string`                  | `tel`                         | Autocomplete token                               |
| name              | `string`                  | —                             | Hidden input name for the E.164 value            |
| id                | `string`                  | Generated                     | Number input id                                  |
| required          | `boolean`                 | `false`                       | Native required on the visible input             |
| disabled          | `boolean`                 | `false`                       | Disables the field and the country button        |
| invalid           | `boolean`                 | `false`                       | Forces the error state                           |
| validate          | `boolean`                 | `true`                        | Show the error after blur when the number is bad |
| locale            | `string`                  | Runtime default               | Locale for country names and sorting             |
| countries         | `CountryCode[]`           | All                           | Countries to offer                               |
| priorityCountries | `CountryCode[]`           | `US`, `GB`, `CA`, `AU`        | Pinned at the top of the list                    |
| searchPlaceholder | `string`                  | `Search countries`            | Filter field placeholder                         |
| emptyText         | `string`                  | `No countries found`          | Empty filter message                             |
| countryLabel      | `string`                  | `Country`                     | Prefix of the country button’s accessible name   |
| phoneLabel        | `string`                  | `Phone number`                | Accessible name when `label` is empty            |
| invalidMessage    | `string`                  | `Enter a valid phone number.` | Error text                                       |
| class             | `HTMLAttributes['class']` | —                             | Container classes                                |

Other attributes fall through to the number input.
