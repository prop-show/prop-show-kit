# Slider

> Pick a value or a range with persistent value badges and minimum / maximum labels. Inspired by [Kumo Slider](https://kumo-ui.com/components/slider/).

::slider-preview
::

## Install

:registry-install{url="/r/slider.json"}

## Usage

```vue
<script setup lang="ts">
import { ref } from "vue";
import { Slider } from "@/components/slider";

const volume = ref([40]);
</script>

<template>
  <Slider v-model="volume" label="Volume" class="w-72" />
  <Slider
    label="Price range"
    :default-value="[25, 75]"
    :get-aria-label="(index) => (index === 0 ? 'Minimum price' : 'Maximum price')"
    class="w-72"
  />
</template>
```

Values follow Reka UI's array API: `[40]` for a single thumb and `[25, 75]` for a range. Use `default-value` for uncontrolled state or `v-model` for controlled state.

## Examples

Single values, ranges, custom bounds, percentage formatting, both sizes, controlled state and disabled state.

```vue
<Slider label="Match count" :default-value="[2]" :max="5" />

/>
<Slider label="Small" size="sm" :default-value="[30]" />
<Slider label="Locked" :default-value="[70]" disabled />
```

## Accessibility

Provide a visible `label` or `getAriaLabel`. For ranges, use `getAriaLabel` to distinguish the thumbs. Arrow keys, Page Up / Page Down and Home / End are handled by Reka UI. Formatted values are announced through `aria-valuetext`; visual badges and endpoint labels are hidden from assistive technology.

## Props

| Name                  | Type                        | Default         | Description                                     |
| :-------------------- | :-------------------------- | :-------------- | :---------------------------------------------- |
| modelValue            | `number[]`                  | —               | Controlled values (`v-model`)                   |
| defaultValue          | `number[]`                  | `[min]`         | Initial uncontrolled values                     |
| label                 | `string`                    | —               | Visible label above the track                   |
| getAriaLabel          | `(index: number) => string` | —               | Accessible name for each thumb                  |
| size                  | `'sm' \| 'base'`            | `'base'`        | Track and thumb size                            |
| min                   | `number`                    | `0`             | Minimum value                                   |
| max                   | `number`                    | `100`           | Maximum value                                   |
| step                  | `number`                    | `1`             | Value increment                                 |
| format                | `Intl.NumberFormatOptions`  | —               | Badge, endpoint and accessible value formatting |
| locale                | `string`                    | Runtime default | Number formatting locale                        |
| disabled              | `boolean`                   | `false`         | Prevents interaction                            |
| minStepsBetweenThumbs | `number`                    | `0`             | Minimum separation in steps                     |
| name                  | `string`                    | —               | Form field name                                 |
| dir                   | `'ltr' \| 'rtl'`            | Inherited       | Reading direction                               |
| class                 | `HTMLAttributes['class']`   | —               | Container classes                               |

Keep initial and controlled values sorted and within the configured bounds. Set `min < max` and a positive `step`.

## Events

| Name              | Payload    | Description                               |
| :---------------- | :--------- | :---------------------------------------- |
| update:modelValue | `number[]` | Values changed by pointer or keyboard     |
| valueCommit       | `number[]` | Final values at the end of an interaction |
