# Notification Center

> An inbox panel for product notifications. Mark one item read, mark them all, dismiss a row, and show an empty state.

::notification-center-preview
::

## Install

:registry-install{url="/r/notification-center.json"}

## Usage

```vue
<script setup lang="ts">
import { ref } from "vue";
import { NotificationCenter } from "@/components/notification-center";
import type { NotificationItem } from "@/components/notification-center";

const items = ref<NotificationItem[]>([
  {
    id: "deploy",
    title: "Deployment finished",
    body: "kit.prop.show is ready on main.",
    createdAt: "2026-10-31T12:00:00.000Z",
  },
]);

function onOpen(item: NotificationItem) {
  // Persist item.read and follow item.href in your app.
  console.info(item.id, item.read);
}
</script>

<template>
  <NotificationCenter v-model="items" class="max-w-md" @open="onOpen" />
</template>
```

`v-model` is the notification list. Opening a row sets `read` to `true` and emits `open` with the updated item. `mark-read`, `mark-all-read`, and `dismiss` fire when that state changes so you can save it. This component does not call an API.

Omit `read`, or set it to `false`, for an unread row. `createdAt` accepts a `Date`, epoch milliseconds, or a date string. The visible label is a short English relative time. After a week it becomes a UTC `YYYY-MM-DD` day. An unparseable value is left blank. Give each item a unique `id`.

`v-model:filter` is `"all"` or `"unread"`. The unread tab is empty when every remaining item is read, and that empty state can switch the filter back to all. Dismissing the last item uses the caught-up empty state. Replace either one with the `empty` slot. The `item` slot replaces the title and body and still receives the item.

```vue
<NotificationCenter v-model="items" v-model:filter="filter">
  <template #item="{ item }">
    <span class="block text-sm font-medium">{{ item.title }}</span>
  </template>
</NotificationCenter>
```

A row with `href` is a link. A row without `href` is a button. Dismiss stays a separate control.

## Accessibility

The panel is labelled by its heading. The unread count is in a polite live region. All and Unread are tabs: arrow keys move the selection, Home selects All, and End selects Unread. Unread rows include the word “Unread” for assistive tech. Each dismiss button is named with the item title. The list scrolls inside the panel.

## Props

| Name                   | Type                      | Default                                   | Description                         |
| :--------------------- | :------------------------ | :---------------------------------------- | :---------------------------------- |
| modelValue             | `NotificationItem[]`      | `[]`                                      | Inbox items (`v-model`)             |
| filter                 | `'all' \| 'unread'`       | `'all'`                                   | Visible subset (`v-model:filter`)   |
| title                  | `string`                  | `Notifications`                           | Heading                             |
| markAllLabel           | `string`                  | `Mark all read`                           | Header action                       |
| allLabel               | `string`                  | `All`                                     | All tab                             |
| unreadLabel            | `string`                  | `Unread`                                  | Unread tab                          |
| emptyTitle             | `string`                  | `You're all caught up`                    | Empty inbox heading                 |
| emptyDescription       | `string`                  | `New notifications will show up here.`    | Empty inbox text                    |
| unreadEmptyTitle       | `string`                  | `No unread notifications`                 | Empty unread filter heading         |
| unreadEmptyDescription | `string`                  | `Everything in this inbox has been read.` | Empty unread filter text            |
| showAllLabel           | `string`                  | `Show all`                                | Action on the unread empty state    |
| dismissLabel           | `string`                  | `Dismiss`                                 | Prefix for each dismiss button name |
| class                  | `HTMLAttributes['class']` | —                                         | Panel classes                       |

## Events

| Name              | Payload              | Description                           |
| :---------------- | :------------------- | :------------------------------------ |
| update:modelValue | `NotificationItem[]` | Next list after read or dismiss       |
| update:filter     | `'all' \| 'unread'`  | Next filter                           |
| open              | `NotificationItem`   | Row activated. `read` is already true |
| mark-read         | `string`             | Id of a row that just became read     |
| mark-all-read     | —                    | At least one row was unread           |
| dismiss           | `string`             | Id removed from the list              |

`unreadCount`, `visibleNotifications`, `markNotificationRead`, `markAllNotificationsRead`, `dismissNotification`, and `formatNotificationTime` are exported from the same entry if you need the same rules outside the panel.
