# Pricing Plan

> A pricing card with a price, billing details, features and an action. Compose multiple cards with [Pricing Plans](/components/pricing-plans) or compare features with [Pricing Table](/components/pricing-table).

::pricing-plan-preview
::

## Install

:registry-install{url="/r/pricing-plan.json"}

## Usage

```vue
<script setup lang="ts">
import { ref } from "vue";
import { SparklesIcon } from "@lucide/vue";
import { PricingPlan, type PricingPlanProps } from "@/components/pricing-plan";

const selected = ref("");
const plan: PricingPlanProps = {
  as: { root: "article", title: "h3" },
  title: "Pro",
  description: "For teams shipping their next product.",
  badge: { label: "Popular", variant: "secondary" },
  price: "$29",
  discount: "$19",
  billingCycle: "per member / month",
  billingPeriod: "Billed annually",
  features: ["Unlimited projects", { title: "Priority support", icon: SparklesIcon }],
  button: { label: "Choose Pro", onClick: () => (selected.value = "Pro selected") },
  terms: "Cancel at any time.",
};
</script>

<template>
  <PricingPlan v-bind="plan" />
  <p role="status">{{ selected }}</p>
</template>
```

Prices are display strings; the component does not calculate discounts, format currency or manage checkout. `price` is the original amount and `discount` is the replacement amount. When `discount` is supplied, the original `price` is struck through. Include the currency and units appropriate to your product.

## Horizontal plan

::pricing-plan-horizontal-preview
::

```vue
<script setup lang="ts">
import { ref } from "vue";
import { PricingPlan } from "@/components/pricing-plan";

const selection = ref("");
</script>

<template>
  <PricingPlan
    title="Team"
    description="A shared workspace for your whole team."
    price="$99"
    billing-cycle="per workspace / month"
    orientation="horizontal"
    :features="['Unlimited members', 'Shared projects', 'Audit logs', 'Priority support']"
    tagline="Everything your team needs"
    :button="{
      label: 'Contact sales',
      onClick: () => (selection = 'Team selected for this demo.'),
    }"
    terms="No payment is collected in this demo."
  />
  <p role="status" class="min-h-5 text-center text-sm text-muted-foreground">
    {{ selection || "Choose a plan to see selection feedback." }}
  </p>
</template>
```

Horizontal plans stack on smaller screens. At `lg` (1024px with the default breakpoints), the body spans two of three columns, features use two columns, and pricing and actions occupy the last column. Vertical plans keep pricing below the header. The default root and title are `div` elements; set `as="article"` or `:as="{ root: 'article', title: 'h3' }"` for your document structure.

## Variants and emphasis

`outline` adds a border on the background surface; `soft` uses a muted surface; `subtle` combines a border and muted surface; `solid` uses the foreground color with inverted text. Choose a contrasting button variant on solid cards.

## Actions

`button` accepts a label plus the installed Button's variant and size, `disabled`, `href`, `target`, `rel` and `onClick`. The default size is `lg` and the button fills the card width. A usable `href` renders an anchor; a disabled link renders a disabled button with no `href`. Supply `onClick` for an action or selection feedback; there is no component-specific selection event or selected state.

```vue
<PricingPlan
  title="Documentation"
  :button="{
    label: 'Read the guide',
    href: 'https://example.com/guide',
    target: '_blank',
    rel: 'noopener noreferrer',
    variant: 'outline',
  }"
/>
<PricingPlan title="Enterprise" :button="{ label: 'Coming soon', disabled: true }" />
```

## Slots

Slots replace their corresponding default content and have no scoped payload. Leaf slots keep the surrounding layout; `body` and `footer` replace whole regions.

```vue
<script setup lang="ts">
import { PricingPlan } from "@/components/pricing-plan";
import { Button } from "@/components/ui/button";
</script>

<template>
  <PricingPlan title="Enterprise" price="Custom" :as="{ root: 'article', title: 'h3' }">
    <template #badge><span class="text-xs font-medium">For larger teams</span></template>
    <template #description>Security and support tailored to your organization.</template>
    <template #price>Let's talk</template>
    <template #billing><span>Annual agreement</span></template>
    <template #features>
      <ul class="space-y-2 text-sm">
        <li>Dedicated onboarding</li>
        <li>Custom service agreement</li>
      </ul>
    </template>
    <template #button><Button as="a" href="/contact">Contact sales</Button></template>
    <template #terms><a href="/terms">Read the service terms</a></template>
  </PricingPlan>
</template>
```

| Slot          | Replaces                                                       |
| :------------ | :------------------------------------------------------------- |
| `body`        | Header, vertical pricing and feature list                      |
| `header`      | Title, badge and description                                   |
| `title`       | Plan title inside the configured title element                 |
| `description` | Description text inside its paragraph                          |
| `badge`       | Badge beside the title                                         |
| `price`       | Current price (`discount ?? price`)                            |
| `discount`    | Original price inside `del`; requires a truthy `discount` prop |
| `billing`     | Billing period and billing cycle                               |
| `features`    | Entire feature list                                            |
| `footer`      | Tagline, horizontal pricing, button and terms                  |
| `tagline`     | Text above the action area                                     |
| `button`      | Entire CTA, even without a `button` prop                       |
| `terms`       | Terms inside a small centered paragraph                        |

Replacing `body` removes vertical pricing; replacing `footer` removes horizontal pricing. Add your own pricing markup inside those region slots if needed. A billing prop alone does not create the price block: provide `price`, `discount`, or a `price`, `discount` or `billing` slot.

## Props

| Name            | Type                                          | Default      | Description                                                        |
| :-------------- | :-------------------------------------------- | :----------- | :----------------------------------------------------------------- |
| `as`            | `string \| { root?: string; title?: string }` | `'div'`      | Root and title element names; object fields default to `div`       |
| `title`         | `string`                                      | —            | Plan name                                                          |
| `description`   | `string`                                      | —            | Description below the title                                        |
| `badge`         | `string \| PricingPlanBadge`                  | —            | Label or `{ label, variant? }`; variant defaults to `secondary`    |
| `price`         | `string`                                      | —            | Price, or original price when discounted                           |
| `discount`      | `string`                                      | —            | Discounted price to display beside the original                    |
| `billingPeriod` | `string`                                      | —            | Additional billing context, e.g. `billed annually`                 |
| `billingCycle`  | `string`                                      | —            | Unit price period next to the price, e.g. `/month`                 |
| `features`      | `(string \| PricingPlanFeature)[]`            | —            | Strings or `{ title, icon?: Component }`; icons default to a check |
| `button`        | `PricingPlanButton`                           | —            | CTA configuration; `label` is required                             |
| `tagline`       | `string`                                      | —            | Emphasized text in the footer                                      |
| `terms`         | `string`                                      | —            | Small text beneath the CTA                                         |
| `orientation`   | `'vertical' \| 'horizontal'`                  | `'vertical'` | Card layout                                                        |
| `variant`       | `'outline' \| 'solid' \| 'soft' \| 'subtle'`  | `'outline'`  | Card surface                                                       |
| `highlight`     | `boolean`                                     | —            | Primary inset ring                                                 |
| `scale`         | `boolean`                                     | —            | Scale to 110% from `lg` upward                                     |
| `class`         | `HTMLAttributes['class']`                     | —            | Root classes                                                       |

The index exports `PricingPlan`, `PricingPlanProps`, `PricingPlanFeature`, `PricingPlanButton` and `PricingPlanBadge`. Feature icons are decorative; include their meaning in the feature title. Give CTAs clear labels and announce application-owned selection feedback with `role="status"` as in the usage example.
