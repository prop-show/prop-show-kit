# Avatar Crop

> Crop a profile image. Drag to move it, zoom with the slider, and export a circle or a square.

::avatar-crop-preview
::

## Install

:registry-install{url="/r/avatar-crop.json"}

## Usage

```vue
<script setup lang="ts">
import { ref } from "vue";
import { AvatarCrop } from "@/components/avatar-crop";
import type { AvatarCropResult } from "@/components/avatar-crop";

const cropped = ref<string | null>(null);

function onCrop(result: AvatarCropResult) {
  // result.blob is the file to upload. result.dataUrl matches v-model.
  console.info(result.blob.size);
}
</script>

<template>
  <AvatarCrop v-model="cropped" label="Profile photo" shape="circle" @crop="onCrop" />
</template>
```

`v-model` is the cropped image as a data URL, set when the person applies the crop. Pass `src` to open an existing photo. Without `src`, the empty state asks for a file. Dropping an image on the window replaces the current one.

The crop window is square. `shape="circle"` clips the export to a circle and shows a round mask. `shape="square"` keeps the corners. PNG keeps transparent corners on a circle. JPEG fills those corners with `background`, or white when `background` is omitted.

```vue
<AvatarCrop shape="square" output-type="image/jpeg" :output-size="512" />
```

The parent uploads `blob` from the `crop` event. This component does not send a request.

## Accessibility

The crop window is a focusable `application` with a description of the keyboard. Arrow keys move the image. Plus and minus zoom around the center. Home resets to the cover fit. The zoom control is a labeled slider from 100% to `maxZoom`. The file input keeps an accessible name that switches between “Choose image” and “Replace image”. Errors use `role="alert"`.

## Props

| Name         | Type                                          | Default                  | Description                                   |
| :----------- | :-------------------------------------------- | :----------------------- | :-------------------------------------------- |
| modelValue   | `string \| null`                              | `null`                   | Cropped data URL (`v-model`), set on apply    |
| src          | `string`                                      | —                        | Image URL to edit                             |
| shape        | `'circle' \| 'square'`                        | `'circle'`               | Mask and export clip                          |
| outputSize   | `number`                                      | `256`                    | Exported width and height, clamped to 16–4096 |
| outputType   | `'image/png' \| 'image/jpeg' \| 'image/webp'` | `'image/png'`            | Canvas export type                            |
| quality      | `number`                                      | `0.92`                   | JPEG and WebP quality                         |
| background   | `string`                                      | White for JPEG           | Color under the image before the clip         |
| maxZoom      | `number`                                      | `4`                      | Largest zoom as a multiple of the cover fit   |
| accept       | `string`                                      | PNG, JPEG, WebP, GIF     | `accept` on the file input                    |
| disabled     | `boolean`                                     | `false`                  | Disables the window, slider, and actions      |
| label        | `string`                                      | —                        | Visible label                                 |
| chooseLabel  | `string`                                      | `Choose image`           | Empty-state action                            |
| replaceLabel | `string`                                      | `Replace image`          | Action once an image is loaded                |
| zoomLabel    | `string`                                      | `Zoom`                   | Slider label                                  |
| applyLabel   | `string`                                      | `Apply crop`             | Export action                                 |
| resetLabel   | `string`                                      | `Reset`                  | Return to the centered cover fit              |
| emptyLabel   | `string`                                      | `No image selected`      | Empty-state text                              |
| instructions | `string`                                      | Drag and keyboard hint   | Accessible name of the crop window            |
| loadError    | `string`                                      | Could not open           | Shown when the image fails to load            |
| typeError    | `string`                                      | Choose an image file     | Shown for a non-image file                    |
| exportError  | `string`                                      | Browser blocked the read | Shown when the canvas cannot be read          |
| class        | `HTMLAttributes['class']`                     | —                        | Container classes                             |

The default empty state can be replaced with the `empty` slot.

## Events

| Name              | Payload            | Description                               |
| :---------------- | :----------------- | :---------------------------------------- |
| update:modelValue | `string \| null`   | Cropped data URL after a successful apply |
| crop              | `AvatarCropResult` | `blob`, `dataUrl`, `width`, `height`      |

`initialFrame`, `sourceRect`, and the other helpers in `crop.ts` are exported if you need the same cover, pan, and zoom math outside the component.

## Source

The crop geometry is original PropShow Kit code. It does not vendor cropperjs, vue-advanced-cropper, or another image-crop package.
