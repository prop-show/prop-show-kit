# Inline Tip

> Inline tip component, used to display different types of tip information.

::inline-tip-preview
::

## Install using CLI

:registry-install{url="/r/inline-tip.json"}

## Usage

```vue
<script setup lang="ts">
import { InlineTip } from "@/components/inline-tip";
</script>

<template>
  <InlineTip label="Note">Keep this setting enabled in production.</InlineTip>
</template>
```

## Props

| Name    | Required | Type                                          | Default | Description                     |
| :------ | :------- | :-------------------------------------------- | :------ | :------------------------------ |
| default | `true`   | `string`                                      | -       | The specific content of the tip |
| variant | `false`  | `'info' \| 'warning' \| 'success' \| 'error'` | `info`  | The specific content of the tip |
