# Inline Copy Text

> A compact, borderless copy control for inline IDs and other short values.

::inline-copy-text-preview
::

## Install

:registry-install{url="/r/inline-copy-text.json"}

## Usage

Use `InlineCopyText` for short identifiers and values in dense interfaces such as table cells. Use [Copy](/components/copy) when the value needs a standalone, always-visible copy button.

The copy icon appears when the control is hovered or focused. It also responds to an enclosing unnamed Tailwind `group`, so table rows can reveal the icon when the row is hovered. After a successful copy the icon becomes a checkmark and the copied message is announced to assistive technology.

```vue
<script setup lang="ts">
import { InlineCopyText } from "@/components/inline-copy-text";
</script>

<template>
  <InlineCopyText :labels="{ copyAction: 'Copy database ID', copied: 'Database ID copied' }">
    f86b3f10-32e9-4db7-ae95-84a1b2c3d4e5
  </InlineCopyText>
</template>
```

### Resource row

An enclosing Tailwind `group` reveals the copy icon when the whole row is hovered or receives focus.

```vue
<template>
  <div
    class="group flex w-full items-center justify-between gap-4 rounded-lg border bg-muted px-4 py-3"
  >
    <span class="min-w-0 truncate text-sm text-foreground">Production database</span>
    <InlineCopyText :labels="{ copyAction: 'Copy database ID', copied: 'Database ID copied' }">
      f86b3f10-32e9-4db7-ae95-84a1b2c3d4e5
    </InlineCopyText>
  </div>
</template>
```

### Rich content

String slot children are copied by default. When the children are not a string, provide the required `value` prop with the value to copy.

```vue
<template>
  <InlineCopyText value="f86b3f10-32e9-4db7-ae95-84a1b2c3d4e5" variant="body">
    <span>Database ID: <strong>f86b3f10…</strong></span>
  </InlineCopyText>
</template>
```

## Props

| Name     | Required | Type                                                                          | Default          | Description                                                                                                                    |
| :------- | :------- | :---------------------------------------------------------------------------- | :--------------- | :----------------------------------------------------------------------------------------------------------------------------- |
| labels   | `false`  | `{ copyAction?: string; copied?: string; unsupported?: string }`              | -                | Accessible labels for localization.                                                                                            |
| value    | `false`  | `string`                                                                      | -                | The value to copy. Required when the default slot is not a string.                                                             |
| variant  | `false`  | `'body' \| 'secondary' \| 'success' \| 'error' \| 'mono' \| 'mono-secondary'` | `mono-secondary` | Text variant. Heading variants are not supported.                                                                              |
| size     | `false`  | `'xs' \| 'sm' \| 'base' \| 'lg'`                                              | -                | Text size. Supported values depend on the variant: body variants accept all sizes, monospace variants accept `'lg'` only.      |
| bold     | `false`  | `boolean`                                                                     | -                | Whether to use medium font weight. Only applies to body variants.                                                              |
| truncate | `false`  | `boolean`                                                                     | `true`           | Whether to truncate overflowing text with an ellipsis.                                                                         |
| as       | `false`  | `InlineCopyTextElement`                                                       | `span`           | The phrasing element used to render the text (the control itself is a `<button>`, so block and flow elements are not allowed). |
| class    | `false`  | `HTMLAttributes['class']`                                                     | -                | Additional classes applied to the root button.                                                                                 |

## Emits

| Name  | Payload      | Description                                                                   |
| :---- | :----------- | :---------------------------------------------------------------------------- |
| click | `MouseEvent` | Emitted when the control is clicked. Call `preventDefault()` to skip copying. |
| copy  | -            | Emitted after the value is written to the clipboard.                          |

## Slots

| Name    | Description                                                           |
| :------ | :-------------------------------------------------------------------- |
| default | Content to display. String children are copied unless `value` is set. |
