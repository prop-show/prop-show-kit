# Layer Card

> A layered card for navigation, feature highlights and grouped content.

::layer-card-preview
::

## Install using CLI

:registry-install{url="/r/layer-card.json"}

## Usage

```vue
<script setup lang="ts">
import { LayerCard, LayerCardPrimary, LayerCardSecondary } from "@/components/layer-card";
</script>

<template>
  <LayerCard class="max-w-sm">
    <LayerCardSecondary>Getting started</LayerCardSecondary>
    <LayerCardPrimary>
      <p class="text-sm text-muted-foreground">Quick start guide for new users.</p>
    </LayerCardPrimary>
  </LayerCard>
</template>
```

`LayerCardSecondary` provides the muted outer layer. `LayerCardPrimary` sits above it with its own rounded surface. Keep these sections as direct children of `LayerCard`; the layered treatment is selected with CSS `:has()`. Vue fragments and conditional sections work without inspecting slots or maintaining state.

### Surface-style card

Render content directly and add your own padding for a simple card surface.

```vue
<LayerCard class="max-w-sm p-4">
  Quick start guide for new users.
</LayerCard>
```

### Secondary footer

Place the secondary section after the primary section to use it as a footer.

```vue
<LayerCard>
  <LayerCardPrimary>All changes have been saved.</LayerCardPrimary>
  <LayerCardSecondary class="text-sm">Updated just now</LayerCardSecondary>
</LayerCard>
```

### Link card

Use `as="a"` and `href`, or `as-child` with a router link, to make the whole card a link. Add a visible keyboard focus style and avoid nested buttons or links inside a linked card.

```vue
<LayerCard
  as="a"
  href="/guide/introduction"
  class="no-underline focus-visible:outline-2 focus-visible:outline-offset-4 focus-visible:outline-ring"
>
  <LayerCardSecondary>Documentation</LayerCardSecondary>
  <LayerCardPrimary>Read the introduction</LayerCardPrimary>
</LayerCard>
```

## API

### LayerCard

| Prop      | Type                      | Default | Description                                     |
| :-------- | :------------------------ | :------ | :---------------------------------------------- |
| `as`      | `PrimitiveProps['as']`    | `'div'` | Root element or component.                      |
| `asChild` | `boolean`                 | `false` | Merge root attributes into a single slot child. |
| `class`   | `HTMLAttributes['class']` | -       | Classes merged with the defaults.               |

### LayerCardPrimary and LayerCardSecondary

Both render a `div` and accept `class: HTMLAttributes['class']`. All three components accept a default slot and forward native attributes and listeners, including `aria-*` and `data-testid`, to their root element. They expose `data-slot="layer-card"`, `data-slot="layer-card-primary"` and `data-slot="layer-card-secondary"` respectively.

There are no custom events or internal state. Use semantic headings inside sections as appropriate for your page. Width, spacing and typography can be customized with classes; colors use the existing Shadcn theme tokens.
