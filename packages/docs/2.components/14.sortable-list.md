# Sortable List

> Reorder a list by dragging a handle, or with the keyboard.

::sortable-list-preview
::

## Install

:registry-install{url="/r/sortable-list.json"}

## Usage

```vue
<script setup lang="ts">
import { ref } from "vue";
import { SortableList } from "@/components/sortable-list";
import type { SortableItem } from "@/components/sortable-list";

const sections = ref<SortableItem[]>([
  { id: "hero", label: "Hero", description: "Opening statement" },
  { id: "proof", label: "Proof", description: "Logos and quotes" },
  { id: "pricing", label: "Pricing", description: "Plans and comparison" },
]);
</script>

<template>
  <SortableList v-model="sections" label="Page sections" />
</template>
```

`v-model` is the ordered array. Each `id` must be unique. The component does not save the order: the parent owns the array and replaces it when a row moves.

Drag the handle with a pointer. Arrow keys move focus between handles. Space or Enter picks up the focused row, the arrow keys move it, Home and End send it to the start or end, Space or Enter drops it, and Escape puts it back where the drag started.

```vue
<SortableList v-model="sections" label="Page sections">
  <template #item="{ item }">
    <span class="text-sm font-medium">{{ item.label }}</span>
  </template>
</SortableList>
```

The handle stays outside the slot. `disabled` on the list locks every handle. `disabled` on one item locks that handle; other rows can still move past it.

## Accessibility

The list is named by `label`. Each handle is a button named `Reorder {label}`, described by `instructions`. `aria-pressed` is true while that row is picked up. Arrow keys move focus until a row is picked up, then they move the row. Status changes go to a polite live region: grabbed, moved, dropped, and cancelled, including the 1-based position. A disabled handle is not in the tab order.

## Props

| Name         | Type                      | Default                | Description                        |
| :----------- | :------------------------ | :--------------------- | :--------------------------------- |
| modelValue   | `T[]`                     | —                      | Ordered items (`v-model`)          |
| label        | `string`                  | —                      | Visible label and accessible name  |
| disabled     | `boolean`                 | `false`                | Disables every handle              |
| instructions | `string`                  | Keyboard hint          | Accessible description of a handle |
| emptyLabel   | `string`                  | `No items to reorder.` | Shown when the list is empty       |
| class        | `HTMLAttributes['class']` | —                      | Container classes                  |

`T` extends `SortableItem`:

| Field       | Type      | Description                                         |
| :---------- | :-------- | :-------------------------------------------------- |
| id          | `string`  | Stable identity. Required and unique                |
| label       | `string`  | Default row text and the name used in announcements |
| description | `string`  | Optional second line                                |
| disabled    | `boolean` | This handle cannot pick up the row                  |

## Events

| Name              | Payload                                 | Description                                   |
| :---------------- | :-------------------------------------- | :-------------------------------------------- |
| update:modelValue | `T[]`                                   | Next order, or the order restored by Escape   |
| reorder           | `{ item: T; from: number; to: number }` | One move. `to` is the index in the next order |

Escape restores the order from when the row was picked up and does not emit `reorder`. Pointer drags announce the final position on drop. Keyboard moves announce each step.

## Slot

| Name | Props                        | Description                   |
| :--- | :--------------------------- | :---------------------------- |
| item | `{ item: T; index: number }` | Row content beside the handle |

## Source

The drag-and-drop behavior is original PropShow Kit code. It does not include `@dnd-kit`, `sortablejs`, `vuedraggable`, or another drag-and-drop library.

`moveItem`, `dropIndex`, `announcement`, and `itemLabel` are exported from the same entry if you need the same order rules outside the list.
