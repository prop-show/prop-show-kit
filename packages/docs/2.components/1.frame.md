# Frame

> A composable container for panels, notifications and framed dialogs.

::frame-preview
::

## Install using CLI

:registry-install{url="/r/frame.json"}

## Usage

```vue
<script setup lang="ts">
import {
  Frame,
  FramePanel,
  FrameHeader,
  FrameTitle,
  FrameDescription,
  FrameFooter,
} from "@/components/frame";
</script>

<template>
  <Frame class="w-full max-w-lg">
    <FrameHeader>
      <FrameTitle>Workspace</FrameTitle>
      <FrameDescription>Recent activity</FrameDescription>
    </FrameHeader>
    <FramePanel patterned>
      <FrameTitle>Changes saved</FrameTitle>
      <FrameDescription>Your workspace is up to date.</FrameDescription>
    </FramePanel>
    <FrameFooter>All changes have been synced.</FrameFooter>
  </Frame>
</template>
```

## Panel layouts

Panels are separated by default. Use `stacked` to join adjacent panels, and `dense` to remove the outer padding. Panel content retains its padding. Only adjacent, direct-child panels are joined; wrappers break the stack.

::frame-layouts-preview
::

```vue
<Frame stacked dense>
  <FramePanel>First panel</FramePanel>
  <FramePanel>Second panel</FramePanel>
  <FrameFooter>2 events</FrameFooter>
</Frame>
```

Use `variant="ghost"` for a transparent outer border, `spacing="sm"` or `spacing="lg"` for outer spacing, and `tone="info"` or `tone="destructive"` for colored borders and footers. Apply `patterned` to a panel to add the reference design's subtle dot texture.

## Inside a dialog

`FrameDialog` adds a modal overlay, focus trapping, focus restoration and an accessible name through Reka UI. Its content uses the same panels and footers as an inline Frame. `v-model:open` lets the parent control visibility; the default slot exposes `close()` for action buttons.

::frame-dialog-preview
::

```vue
<script setup lang="ts">
import { ref } from "vue";
import { Button } from "@/components/ui/button";
import {
  FrameDialog,
  FramePanel,
  FrameTitle,
  FrameDescription,
  FrameFooter,
} from "@/components/frame";

const open = ref(false);
</script>

<template>
  <FrameDialog
    v-model:open="open"
    title="Changes saved"
    description="Your workspace is up to date."
    tone="info"
  >
    <template #trigger>
      <Button>Open dialog</Button>
    </template>
    <template #default="{ close }">
      <FramePanel patterned class="pr-12">
        <FrameTitle>Changes saved</FrameTitle>
        <FrameDescription>Your workspace is up to date.</FrameDescription>
      </FramePanel>
      <FrameFooter class="justify-end">
        <Button variant="ghost" @click="close">Dismiss</Button>
      </FrameFooter>
    </template>
  </FrameDialog>
</template>
```

The trigger slot accepts one focusable element or button component. It is optional when opening programmatically. Keep `pr-12` on content beside the built-in close button. With `dismissible="false"` (bind as `:dismissible="false"` in Vue), provide an explicit action that calls `close()` or updates `open`.

Frame is a visual container: it does not announce messages, start timers, delete records or manage notifications. Add appropriate live-region semantics for asynchronous status messages and implement business actions in the parent. For a timed message, update `open` in your own timer, clean it up on unmount, and allow enough time to read or act. Do not auto-dismiss a dialog while the user is interacting with it.

## API

### Frame

| Prop      | Type                                   | Default     | Description                                                |
| :-------- | :------------------------------------- | :---------- | :--------------------------------------------------------- |
| `variant` | `'default' \| 'ghost'`                 | `'default'` | Outer border style.                                        |
| `tone`    | `'default' \| 'info' \| 'destructive'` | `'default'` | Background, panel border and footer tone.                  |
| `spacing` | `'sm' \| 'default' \| 'lg'`            | `'default'` | Outer padding and gap: 2, 4 or 8px.                        |
| `stacked` | `boolean`                              | `false`     | Join adjacent direct-child panels with shared borders.     |
| `dense`   | `boolean`                              | `false`     | Remove outer padding and gaps; panels meet the frame edge. |
| `class`   | `HTMLAttributes['class']`              | -           | Classes merged with the defaults.                          |

Use `class="[--frame-radius:0.5rem]"` to customize the outer radius. The default is 8px; panels derive their radius from it.

### FramePanel

| Prop        | Type                      | Default | Description                                                     |
| :---------- | :------------------------ | :------ | :-------------------------------------------------------------- |
| `patterned` | `boolean`                 | `false` | Decorative dot texture on the right.                            |
| `fit`       | `boolean`                 | `false` | Keep content height instead of growing into spare frame height. |
| `class`     | `HTMLAttributes['class']` | -       | Classes merged with the defaults.                               |

### FrameHeader, FrameTitle, FrameDescription, FrameFooter

Each accepts `class: HTMLAttributes['class']` and a default slot. Native attributes and listeners are forwarded to the root element. `FrameTitle` renders `h3`; `FrameDescription` renders `p`; the other parts render `div`. Adjust heading semantics with `role="heading"` and `aria-level` when needed. Headers and footers can be placed inside or outside panels.

All presentation components expose their kebab-case name as `data-slot`, for example `data-slot="frame-panel"`. They have no custom events or internal state.

### FrameDialog

| Prop                    | Type      | Default   | Description                                                                         |
| :---------------------- | :-------- | :-------- | :---------------------------------------------------------------------------------- |
| `open` / `v-model:open` | `boolean` | `false`   | Visibility; also works without a model when using the trigger.                      |
| `title`                 | `string`  | Required  | Accessible name, rendered visually hidden. Add a visible `FrameTitle` in the panel. |
| `description`           | `string`  | -         | Optional visually hidden accessible description.                                    |
| `dismissible`           | `boolean` | `true`    | Show the close button and allow Escape/outside-click dismissal.                     |
| `closeLabel`            | `string`  | `'Close'` | Accessible close-button label; localize as needed.                                  |

Frame layout props (`variant`, `tone`, `spacing`, `stacked`, `dense`), `class`, native attributes and listeners are forwarded to the inner Frame. The default width is `max-w-lg`, constrained to the viewport; tall content scrolls. It renders in a portal under `body`, so theme tokens must be available there. For a locally scoped theme, pass the theme class to `FrameDialog`.

| Slot / Event  | API                          | Description                                      |
| :------------ | :--------------------------- | :----------------------------------------------- |
| `trigger`     | One button element/component | Optional opener; focus returns here after close. |
| `default`     | `{ close: () => void }`      | Frame panels, footer and actions.                |
| `update:open` | `(open: boolean) => void`    | Fired when visibility changes.                   |

## Reference

The composition and layout API are inspired by [ReUI Frame](https://reui.io/components/frame). This Vue implementation adds semantic tones, an optional panel texture and `FrameDialog` for modal use.
