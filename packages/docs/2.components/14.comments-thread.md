# Comments Thread

> A discussion list with replies nested under each comment.

::comments-thread-preview
::

## Install

:registry-install{url="/r/comments-thread.json"}

## Usage

```vue
<script setup lang="ts">
import { ref } from "vue";
import { CommentsThread } from "@/components/comments-thread";
import type { CommentAuthor, CommentItem } from "@/components/comments-thread";

const author: CommentAuthor = { name: "You" };
const comments = ref<CommentItem[]>([
  {
    id: "layout",
    author: { name: "Ada Lovelace" },
    body: "The preview frame should stay inside the page width on a phone.",
    createdAt: "2026-10-31T12:00:00.000Z",
    replies: [
      {
        id: "layout-reply",
        author: { name: "Grace Hopper" },
        body: "I can reproduce it when the sidebar is open.",
        createdAt: "2026-10-31T12:30:00.000Z",
      },
    ],
  },
]);

function onSubmit(comment: CommentItem, parentId: string | null) {
  // Persist comment under parentId. null is a new top-level comment.
  console.info(comment.id, parentId);
}
</script>

<template>
  <CommentsThread v-model="comments" :author="author" class="max-w-xl" @submit="onSubmit" />
</template>
```

`v-model` is the comment tree. `author` is the person new comments and replies are attributed to. Submitting the composer appends a comment and emits `submit` with that comment and the parent id. A top-level comment uses `null`. This component does not call an API.

Each comment needs a unique `id`. `createdAt` accepts a `Date`, epoch milliseconds, or a date string. The visible label is a short English relative time. After a week it becomes a UTC `YYYY-MM-DD` day. An unparseable value is left blank. `replies` is the nested list. Omit it when a comment has no replies.

`avatarUrl` is optional. Without it, the avatar shows initials from the name. A blank body, a blank id, or a blank author name is not posted. `maxDepth` is the deepest comment that can exist. A top-level comment is depth 1, and the default limit is 3, so a reply can be nested once more under a reply. A comment at the limit has no reply button. A non-integer or non-positive `maxDepth` behaves as 1.

`replyToLabel` may include `{name}`, which is replaced with the author being replied to. The `comment` slot replaces the body and still receives the comment. The `empty` slot replaces the empty state. The composer stays either way.

```vue
<CommentsThread v-model="comments" :author="author">
  <template #comment="{ comment }">
    <p class="text-sm">{{ comment.body }}</p>
  </template>
</CommentsThread>
```

`v-model:draft` is the top-level composer text. Reply drafts stay inside the open reply composer. Opening another reply discards the previous draft. The preview names above are sample copy.

## Accessibility

The section is labelled by its heading. The comment count is available to assistive tech. Each comment is an article named by its author, and replies are a nested list. Reply announces who it addresses, and sets `aria-expanded` while the reply composer is open. The composer label names that person. Enter inserts a newline. Ctrl+Enter or Cmd+Enter submits. Escape cancels a reply. The submit button stays disabled until the body has non-whitespace text. A polite live region announces when a comment or reply is posted.

## Props

| Name             | Type                      | Default                                    | Description                                     |
| :--------------- | :------------------------ | :----------------------------------------- | :---------------------------------------------- |
| modelValue       | `CommentItem[]`           | `[]`                                       | Comment tree (`v-model`)                        |
| draft            | `string`                  | `''`                                       | Top-level composer text (`v-model:draft`)       |
| author           | `CommentAuthor`           | —                                          | Person new comments are attributed to           |
| title            | `string`                  | `Comments`                                 | Heading                                         |
| replyLabel       | `string`                  | `Reply`                                    | Reply button                                    |
| cancelLabel      | `string`                  | `Cancel`                                   | Close the reply composer                        |
| commentLabel     | `string`                  | `Comment`                                  | Top-level submit button                         |
| replySubmitLabel | `string`                  | `Reply`                                    | Reply submit button                             |
| placeholder      | `string`                  | `Write a comment`                          | Top-level composer label and placeholder        |
| replyPlaceholder | `string`                  | `Write a reply`                            | Reply composer placeholder                      |
| replyToLabel     | `string`                  | `Reply to {name}`                          | Reply composer label. `{name}` is the author    |
| emptyTitle       | `string`                  | `No comments yet`                          | Empty thread heading                            |
| emptyDescription | `string`                  | `Start the thread with the first comment.` | Empty thread text                               |
| maxDepth         | `number`                  | `3`                                        | Deepest comment depth. Top-level comments are 1 |
| createId         | `() => string`            | random id                                  | Id for a comment created in the composer        |
| class            | `HTMLAttributes['class']` | —                                          | Section classes                                 |

## Events

| Name              | Payload                         | Description                                  |
| :---------------- | :------------------------------ | :------------------------------------------- |
| update:modelValue | `CommentItem[]`                 | Next tree after a comment or reply is posted |
| update:draft      | `string`                        | Next top-level composer text                 |
| submit            | `[CommentItem, string \| null]` | Posted comment, and the parent id or `null`  |

`countComments`, `findComment`, `commentDepth`, `canReply`, `addComment`, `createComment`, `commentInitials`, and `formatCommentTime` are exported from the same entry if you need the same rules outside the thread.

## Slots

| Name    | Props         | Description               |
| :------ | :------------ | :------------------------ |
| comment | `{ comment }` | Replaces one comment body |
| empty   | —             | Replaces the empty thread |
