# Signature Pad

> Capture a handwritten signature, clear it, and export the drawing as a data URL or a Blob.

::signature-pad-preview
::

## Install

:registry-install{url="/r/signature-pad.json"}

## Usage

```vue
<script setup lang="ts">
import { ref } from "vue";
import { SignaturePad } from "@/components/signature-pad";
import type { SignatureExport } from "@/components/signature-pad";

const signature = ref<string | null>(null);

function onExport(result: SignatureExport) {
  // result.blob is the file to upload. result.dataUrl matches v-model.
  console.info(result.blob.size, result.dataUrl.startsWith("data:image/png"));
}
</script>

<template>
  <SignaturePad v-model="signature" label="Signature" @export="onExport" />
</template>
```

Draw with a mouse, finger, or pen. A tap leaves a dot. A drag follows the pointer and stays inside the pad. `v-model` is the last saved data URL. It stays `null` until Save signature, and drawing, undo, or clear sets it back to `null`.

`exportSignature()`, `toDataURL()`, and `toBlob()` are on the component ref. `exportSignature()` saves into `v-model` and emits `export`. `toDataURL()` and `toBlob()` read the current drawing without changing `v-model`. All three return `null` when the pad is empty.

```vue
<SignaturePad ref="pad" output-type="image/jpeg" background="#ffffff" />
```

PNG and WebP keep a transparent background unless `background` is set. JPEG has no transparency, so a missing `background` is white. The dashed baseline is only a guide and is not part of the exported image. The component does not upload the file.

## Accessibility

The pad is a focusable canvas named by `label`, or by `instructions` when there is no label. `instructions` also describe the keyboard: Backspace undoes the last stroke and Delete clears the signature. Undo, Clear, and Save signature are buttons, and they stay disabled until there is a stroke. Status changes are announced in a polite live region. Export failures use `role="alert"`.

## Props

| Name          | Type                                          | Default                | Description                              |
| :------------ | :-------------------------------------------- | :--------------------- | :--------------------------------------- |
| modelValue    | `string \| null`                              | `null`                 | Last saved data URL (`v-model`)          |
| label         | `string`                                      | —                      | Visible label and accessible name        |
| penColor      | `string`                                      | `#171717`              | Ink color                                |
| background    | `string`                                      | White for JPEG         | Color under the ink in the exported file |
| strokeWidth   | `number`                                      | `2.25`                 | Ink width in CSS pixels, capped at 32    |
| outputType    | `'image/png' \| 'image/jpeg' \| 'image/webp'` | `'image/png'`          | Canvas export type                       |
| quality       | `number`                                      | `0.92`                 | JPEG and WebP quality, clamped to 0–1    |
| disabled      | `boolean`                                     | `false`                | Disables drawing and the actions         |
| emptyLabel    | `string`                                      | `Sign here`            | Hint shown until the first point         |
| clearLabel    | `string`                                      | `Clear`                | Clear button                             |
| undoLabel     | `string`                                      | `Undo`                 | Undo button                              |
| exportLabel   | `string`                                      | `Save signature`       | Export button                            |
| instructions  | `string`                                      | Pointer and key hint   | Accessible description of the pad        |
| emptyStatus   | `string`                                      | `Signature is empty.`  | Initial live-region text                 |
| signedStatus  | `string`                                      | `Stroke added.`        | Live region after a stroke               |
| clearedStatus | `string`                                      | `Signature cleared.`   | Live region after clear                  |
| undoStatus    | `string`                                      | `Last stroke removed.` | Live region after undo                   |
| savedStatus   | `string`                                      | `Signature saved.`     | Live region after a successful export    |
| exportError   | `string`                                      | Browser blocked read   | Shown when the canvas cannot be read     |
| class         | `HTMLAttributes['class']`                     | —                      | Container classes                        |

The bitmap size follows the pad’s CSS size and the screen pixel ratio, capped at 3. `width` and `height` on the export are those device pixels.

## Events

| Name              | Payload              | Description                                        |
| :---------------- | :------------------- | :------------------------------------------------- |
| update:modelValue | `string \| null`     | Saved data URL, or `null` when the drawing changes |
| export            | `SignatureExport`    | `blob`, `dataUrl`, `width`, and `height`           |
| change            | `{ empty: boolean }` | A stroke ended, or undo / clear changed the ink    |
| clear             | —                    | The pad was cleared                                |
| undo              | —                    | The last stroke was removed                        |

`isSignatureEmpty`, `undoStroke`, `pointFromClient`, `strokeCommands`, and `canvasBackground` are exported from the same entry if you need the same rules outside the pad.
