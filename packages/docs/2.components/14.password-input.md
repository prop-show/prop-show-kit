# Password Input

> A password field with a show/hide toggle and a strength meter. Built on the shadcn-vue input group.

::password-input-preview
::

## Install

:registry-install{url="/r/password-input.json"}

## Usage

```vue
<script setup lang="ts">
import { ref } from "vue";
import { PasswordInput } from "@/components/password-input";

const password = ref("");
</script>

<template>
  <PasswordInput v-model="password" label="New password" class="max-w-sm" />
</template>
```

`v-model` is the password string. The meter is a hint for the person filling the form. It is not a breach check and it does not replace your own password rules on the server.

Hide the meter and the requirement list when the field is for a password the person already has.

```vue
<PasswordInput
  v-model="current"
  label="Current password"
  autocomplete="current-password"
  :show-strength="false"
  :show-requirements="false"
/>
```

## Strength

Five rules are checked: minimum length (8 by default), a lowercase letter, an uppercase letter, a number, and a symbol. The meter has four filled steps.

| Score | Label  | When                                                             |
| :---- | :----- | :--------------------------------------------------------------- |
| 0     |        | The field is empty                                               |
| 1     | Weak   | Shorter than `minLength`, only one rule, or a very common string |
| 2     | Fair   | Two rules                                                        |
| 3     | Good   | Three or four rules                                              |
| 4     | Strong | All five rules, or at least four rules and 12 characters         |

`assessPassword` is exported if you want the same score outside the field.

## Accessibility

The toggle is a button with `aria-pressed` and a label that switches between “Show password” and “Hide password”. The meter uses `role="meter"` with `aria-valuenow` from 0 to 4 and `aria-valuetext` set to the visible label. Each requirement exposes whether it is met. Give the field a visible `label`, or pass an accessible name through `$attrs`.

## Props

| Name              | Type                                 | Default                  | Description                                |
| :---------------- | :----------------------------------- | :----------------------- | :----------------------------------------- |
| modelValue        | `string`                             | `""`                     | Password (`v-model`)                       |
| defaultValue      | `string`                             | —                        | Initial value when uncontrolled            |
| label             | `string`                             | —                        | Visible label                              |
| placeholder       | `string`                             | `Enter a password`       | Input placeholder                          |
| autocomplete      | `string`                             | `new-password`           | Autocomplete token                         |
| name              | `string`                             | —                        | Form field name                            |
| id                | `string`                             | Generated                | Input id                                   |
| required          | `boolean`                            | `false`                  | Native required                            |
| disabled          | `boolean`                            | `false`                  | Disables the field and the toggle          |
| invalid           | `boolean`                            | `false`                  | Sets `aria-invalid`                        |
| minLength         | `number`                             | `8`                      | Length rule and the weak-score cap         |
| showToggle        | `boolean`                            | `true`                   | Show/hide button                           |
| showStrength      | `boolean`                            | `true`                   | Segmented meter                            |
| showRequirements  | `boolean`                            | `true`                   | Rule list                                  |
| showLabel         | `string`                             | `Show password`          | Toggle label while the password is hidden  |
| hideLabel         | `string`                             | `Hide password`          | Toggle label while the password is visible |
| requirementLabels | `Partial<PasswordRequirementLabels>` | —                        | Replacement rule text                      |
| strengthLabels    | `Partial<PasswordStrengthLabels>`    | Weak, Fair, Good, Strong | Replacement meter text                     |
| class             | `HTMLAttributes['class']`            | —                        | Container classes                          |

Other attributes fall through to the input.
