# Layer Dialog

> A responsive layered dialog with a persistent title, scrollable body and fixed actions.

::layer-dialog-preview
::

## Install using CLI

:registry-install{url="/r/layer-dialog.json"}

## Usage

```vue
<script setup lang="ts">
import { ref, useId } from "vue";
import { LayerDialog } from "@/components/layer-dialog";
import { Button } from "@/components/ui/button";
import { Input } from "@/components/ui/input";

const open = ref(false);
const formId = useId();
</script>

<template>
  <LayerDialog
    v-model:open="open"
    title="Configure hostname"
    description="Route requests to your application."
    action-label="Save hostname"
    action-type="submit"
    :form="formId"
    dismiss-label="Cancel"
  >
    <template #trigger><Button>Open settings</Button></template>
    <form :id="formId" @submit.prevent="open = false">
      <label :for="`${formId}-hostname`">Hostname</label>
      <Input :id="`${formId}-hostname`" name="hostname" required />
    </form>
  </LayerDialog>
</template>
```

The body is the default slot. The footer's submit button uses the native `form` attribute, so browser validation still runs. In production, close the dialog only after saving successfully; use `pending` during the request and render errors in the body. For actions without a form, use `@action` with the default `action-type="button"`.

## Informational content

Omit `action-label` for a title-bar close button and no footer. The title stays visible while the body scrolls; the description folds away visually but remains available to assistive technology. Reopening resets the scroll layout.

::layer-dialog-preview{variant="info"}
::

## Confirmation

Set `alert` for Reka UI's alert dialog semantics, initial focus on Cancel and blocked backdrop dismissal. Escape still cancels unless `pending` is set. Use `action-variant="destructive"` for irreversible changes.

::layer-dialog-preview{variant="alert"}
::

## Props

| Prop              | Type                         | Default                | Description                                                    |
| ----------------- | ---------------------------- | ---------------------- | -------------------------------------------------------------- |
| `open`            | `boolean`                    | `false`                | Two-way open state via `v-model:open`.                         |
| `title`           | `string`                     | Required               | Visible and accessible title.                                  |
| `description`     | `string`                     | —                      | Accessible description below the title.                        |
| `alert`           | `boolean`                    | `false`                | Confirmation dialog with Cancel and no title-bar close button. |
| `action-label`    | `string`                     | —                      | Adds one primary action and an automatic dismiss button.       |
| `action-variant`  | `'default' \| 'destructive'` | `'default'`            | Primary button treatment.                                      |
| `action-disabled` | `boolean`                    | `false`                | Disables the primary action.                                   |
| `action-type`     | `'button' \| 'submit'`       | `'button'`             | Native button type.                                            |
| `form`            | `string`                     | —                      | ID of the form associated with the primary action.             |
| `dismiss-label`   | `string`                     | `'Close'` / `'Cancel'` | Dismiss button and close icon accessible label.                |
| `pending`         | `boolean`                    | `false`                | Marks the dialog busy and blocks user dismissal and actions.   |

`@action` receives the primary button's click event. It does not automatically close the dialog. Avoid using it to save a native form: use the form's `@submit` handler so validation runs first.

The `trigger` slot accepts a single interactive element. The default slot receives `{ close }`; `close()` respects `pending`. Additional attributes and classes apply to the dialog surface.

On narrow screens the dialog sits at the bottom with viewport-constrained scrolling. On desktop it is centered. Both layouts retain the title and action footer. Focus trapping, Escape, focus restoration and background scroll locking are handled by Reka UI. This implementation does not include Kumo's split-action menu or swipe dismissal.

## Reference

The visual design and interaction patterns are inspired by [Kumo UI Layer Dialog](https://kumo-ui.com/components/layer-dialog/), including the layered surface, persistent title, scrollable body and fixed action footer. Source: [cloudflare/kumo `layer-dialog`](https://github.com/cloudflare/kumo/tree/main/packages/kumo/src/components/layer-dialog) (MIT, Copyright (c) 2026 Cloudflare, Inc.). This implementation adapts those patterns to Vue props and slots, using Reka UI for accessible dialog behavior and Shadcn Vue theme tokens for styling.
