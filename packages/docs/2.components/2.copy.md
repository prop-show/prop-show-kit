# Copy

> Copy button component, supports custom styles and tooltip text.

::copy-preview
::

## Install

:registry-install{url="/r/copy.json"}

## Usage

```vue
<script setup lang="ts">
import { Copy } from "@/components/copy";
</script>

<template>
  <Copy content="pnpm add vue" />
</template>
```

## Props

| Name              | Required | Type                        | Default   | Description                 |
| :---------------- | :------- | :-------------------------- | :-------- | :-------------------------- |
| content           | `true`   | `string`                    | -         | Content to copy             |
| size              | `false`  | `'sm' \| 'default'`         | `default` | Button size                 |
| variant           | `false`  | `ButtonVariants['variant']` | `outline` | Button style variant        |
| copyTooltipText   | `false`  | `string`                    | `Copy`    | Tooltip text before copying |
| copiedTooltipText | `false`  | `string`                    | `Copied`  | Tooltip text after copying  |
