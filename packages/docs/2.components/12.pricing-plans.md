# Pricing Plans

> A responsive layout for [Pricing Plan](/components/pricing-plan) cards, supplied as data or composed through the default slot.

::pricing-plans-preview
::

## Install

:registry-install{url="/r/pricing-plans.json"}

## Usage with the plans prop

```vue
<script setup lang="ts">
import { ref } from "vue";
import { PricingPlans } from "@/components/pricing-plans";
import type { PricingPlanProps } from "@/components/pricing-plan";

const selected = ref("");
const plans: PricingPlanProps[] = [
  {
    title: "Starter",
    price: "$0",
    billingPeriod: "forever",
    features: ["3 projects", "Community support"],
    button: {
      label: "Choose Starter",
      variant: "outline",
      onClick: () => (selected.value = "Starter selected"),
    },
  },
  {
    title: "Pro",
    price: "$19",
    billingCycle: "per month",
    badge: "Popular",
    highlight: true,
    features: ["Unlimited projects", "Priority support"],
    button: { label: "Choose Pro", onClick: () => (selected.value = "Pro selected") },
  },
];
</script>

<template>
  <PricingPlans :plans="plans">
    <template #terms="{ plan, index }">
      Option {{ index + 1 }}: {{ plan.title }}. Cancel any time.
    </template>
  </PricingPlans>
  <p role="status">{{ selected }}</p>
</template>
```

Every array entry is passed to a Pricing Plan. Named slots are forwarded to every generated card with `{ plan, index }`, where `index` is zero-based. Use the original plan object to vary content; callbacks belong in `button.onClick`. Pricing Plans provides layout rather than checkout or selection state.

## Compose cards with the default slot

::pricing-plans-slotted-preview
::

```vue
<script setup lang="ts">
import { ref } from "vue";
import { PricingPlan } from "@/components/pricing-plan";
import { PricingPlans } from "@/components/pricing-plans";

const selection = ref("");
</script>

<template>
  <PricingPlans>
    <PricingPlan
      title="Starter"
      price="$0"
      :features="['3 projects']"
      :button="{
        label: 'Start building',
        variant: 'outline',
        onClick: () => (selection = 'Starter selected for this demo.'),
      }"
    />
    <PricingPlan
      title="Enterprise"
      price="Custom"
      highlight
      :button="{
        label: 'Contact sales',
        onClick: () => (selection = 'Enterprise selected for this demo.'),
      }"
    >
      <template #features>
        <p class="text-sm text-muted-foreground">Dedicated onboarding and a custom agreement.</p>
      </template>
      <template #terms>Talk to our sales team about a custom plan.</template>
    </PricingPlan>
  </PricingPlans>
  <p role="status" class="min-h-5 text-center text-sm text-muted-foreground">
    {{ selection || "Choose a plan to see selection feedback." }}
  </p>
</template>
```

The nonempty default slot takes precedence over `plans`. Empty slots containing only comments or empty fragments fall back to `plans`. Direct slot children determine the desktop column count; fragments (including `v-for`) are counted recursively, while text and comments are ignored. Put each plan directly inside the layout rather than wrapping all plans in one element. In this mode, configure each card and its slots yourself; wrapper named slots and orientation do not configure slotted children.

## Vertical layout

::pricing-plans-vertical-preview
::

```vue
<script setup lang="ts">
import { ref } from "vue";
import { PricingPlan } from "@/components/pricing-plan";
import { PricingPlans } from "@/components/pricing-plans";

const selection = ref("");
</script>

<template>
  <PricingPlans orientation="vertical">
    <PricingPlan
      title="Team"
      price="$99"
      orientation="horizontal"
      :features="['Unlimited projects', 'Priority support']"
      :button="{
        label: 'Choose Team',
        variant: 'outline',
        onClick: () => (selection = 'Team selected for this demo.'),
      }"
    />
    <PricingPlan
      title="Enterprise"
      price="Custom"
      orientation="horizontal"
      highlight
      :features="['Unlimited projects', 'Priority support']"
      :button="{
        label: 'Contact sales',
        onClick: () => (selection = 'Enterprise selected for this demo.'),
      }"
    />
  </PricingPlans>
  <p role="status" class="min-h-5 text-center text-sm text-muted-foreground">
    {{ selection || "Choose a plan to see selection feedback." }}
  </p>
</template>
```

The default `horizontal` wrapper stacks cards below `lg` and uses equal-width columns at `lg` (1024px by default). Generated cards default to vertical orientation. A `vertical` wrapper always stacks cards and defaults generated cards to horizontal orientation. Each `plans` entry can override this default with its own `orientation`.

## Compact spacing and scaled cards

::pricing-plans-compact-preview

</script>

<template>
  <PricingPlans compact>
    <PricingPlan
      title="Starter"
      price="$0"
      variant="subtle"
      class="rounded-none"
      :features="['3 projects', 'Community support']"
      :button="{
        label: 'Choose Starter',
        variant: 'outline',
        onClick: () => (selection = 'Starter selected for this demo.'),
      }"
    />
    <PricingPlan
      title="Pro"
      price="$19"
      variant="subtle"
      class="rounded-none"
      highlight
      :features="['Unlimited projects', 'Priority support']"
      :button="{
        label: 'Choose Pro',
        onClick: () => (selection = 'Pro selected for this demo.'),
      }"
    />

`compact` removes the horizontal gap between desktop columns. It leaves the vertical gap, card padding, borders and corners intact; use card classes when you want a joined appearance.

::pricing-plans-scale-preview
::

```vue
<script setup lang="ts">
import { ref } from "vue";
import { PricingPlan } from "@/components/pricing-plan";
import { PricingPlans } from "@/components/pricing-plans";

const selection = ref("");
</script>

<template>
  <div class="px-6 py-8">
    <PricingPlans scale>
      <PricingPlan
        title="Starter"
        price="$0"
        :features="['3 projects', 'Community support']"
        :button="{
          label: 'Choose Starter',
          variant: 'outline',
          onClick: () => (selection = 'Starter selected for this demo.'),
        }"
      />
      <PricingPlan
        title="Pro"
        price="$19"
        highlight
        scale
        :features="['Unlimited projects', 'Priority support']"
        :button="{
          label: 'Choose Pro',
          onClick: () => (selection = 'Pro selected for this demo.'),
        }"
      />
    </PricingPlans>
  </div>
  <p role="status" class="min-h-5 text-center text-sm text-muted-foreground">
    {{ selection || "Choose a plan to see selection feedback." }}
  </p>

```

Wrapper `scale` widens the non-compact horizontal gap from `gap-x-8` to `gap-x-13`; it does not enlarge any card. Set `scale` on the featured Pricing Plan (or on its `plans` entry) as well. Cards enlarge to 110% at `lg`; reserve outer space and avoid clipping. With `compact`, neither horizontal gap is applied.

## Shared slots for data-driven cards

```vue
<PricingPlans :plans="plans">
  <template #badge="{ plan }">
    <span v-if="plan.highlight" class="text-xs font-semibold">Recommended</span>
  </template>
  <template #billing="{ plan }">
    <span>{{ plan.billingPeriod }} · Taxes may apply</span>
  </template>
  <template #terms="{ plan }">
    <a :href="plan.title === 'Pro' ? '/terms/pro' : '/terms/starter'">Plan terms</a>
  </template>
</PricingPlans>
```

All Pricing Plan slots are available in data mode: `body`, `header`, `title`, `description`, `badge`, `price`, `discount`, `billing`, `features`, `footer`, `tagline`, `button` and `terms`. Each receives `{ plan: PricingPlanProps, index: number }`. A forwarded slot replaces the corresponding fallback for every card, including when your conditional slot content renders nothing. Region replacement rules follow [Pricing Plan slots](/components/pricing-plan#slots).

## Props

| Name          | Type                         | Default        | Description                                                |
| :------------ | :--------------------------- | :------------- | :--------------------------------------------------------- |
| `as`          | `string`                     | `'div'`        | Root element                                               |
| `plans`       | `PricingPlanProps[]`         | —              | Cards to generate when no default slot is supplied         |
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | Layout direction and generated cards' default orientation  |
| `compact`     | `boolean`                    | —              | Remove horizontal column gaps                              |
| `scale`       | `boolean`                    | —              | Allow extra horizontal spacing for separately scaled cards |
| `class`       | `HTMLAttributes['class']`    | —              | Root classes                                               |

The index exports `PricingPlans`. Import `PricingPlanProps` from `@/components/pricing-plan` for typed data. There are no component-specific events; configure actions per card and keep application state in the parent.
