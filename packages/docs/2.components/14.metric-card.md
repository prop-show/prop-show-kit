# Metric Card

> A KPI card with a value, a label, and an optional delta or trend.

::metric-card-preview
::

The period buttons in the preview are sample page state. They are not part of the component. Switching them replaces the values passed into each card. The numbers are demonstration copy.

## Install

:registry-install{url="/r/metric-card.json"}

## Usage

```vue
<script setup lang="ts">
import type { Component } from "vue";
import { computed, shallowRef } from "vue";
import { BoxesIcon, GlobeIcon, TriangleAlertIcon } from "@lucide/vue";
import { Button } from "@/components/ui/button";
import { MetricCard, MetricCards } from "@/components/metric-card";
import type { MetricTone, MetricTrend } from "@/components/metric-card";

type SampleMetric = {
  label: string;
  value: string;
  description: string;
  icon: Component;
  delta?: string;
  trend?: MetricTrend;
  tone?: MetricTone;
};

const period = shallowRef<"7d" | "30d">("7d");
const summaries: Record<"7d" | "30d", SampleMetric[]> = {
  "7d": [
    {
      label: "Requests",
      value: "128.4k",
      delta: "+18.6%",
      description: "from last week",
      icon: GlobeIcon,
    },
    {
      label: "Error rate",
      value: "0.42%",
      delta: "-0.08%",
      trend: "down",
      tone: "positive",
      description: "from last week",
      icon: TriangleAlertIcon,
    },
    {
      label: "Active projects",
      value: "8",
      description: "Across 3 environments",
      icon: BoxesIcon,
    },
  ],
  "30d": [
    {
      label: "Requests",
      value: "542.8k",
      delta: "+24.2%",
      description: "from last month",
      icon: GlobeIcon,
    },
    {
      label: "Error rate",
      value: "0.31%",
      delta: "-0.19%",
      trend: "down",
      tone: "positive",
      description: "from last month",
      icon: TriangleAlertIcon,
    },
    {
      label: "Active projects",
      value: "12",
      description: "Across 3 environments",
      icon: BoxesIcon,
    },
  ],
};
const metrics = computed(() => summaries[period.value]);
</script>

<template>
  <div class="w-full max-w-4xl space-y-4">
    <div role="group" aria-label="Reporting period" class="flex justify-end gap-1">
      <Button
        type="button"
        size="sm"
        :variant="period === '7d' ? 'secondary' : 'ghost'"
        :aria-pressed="period === '7d'"
        @click="period = '7d'"
      >
        7 days
      </Button>
      <Button
        type="button"
        size="sm"
        :variant="period === '30d' ? 'secondary' : 'ghost'"
        :aria-pressed="period === '30d'"
        @click="period = '30d'"
      >
        30 days
      </Button>
    </div>
    <MetricCards label="Workspace metrics">
      <MetricCard
        v-for="metric in metrics"
        :key="metric.label"
        :label="metric.label"
        :value="metric.value"
        :delta="metric.delta"
        :trend="metric.trend"
        :tone="metric.tone"
        :description="metric.description"
      >
        <template #icon>
          <component :is="metric.icon" />
        </template>
      </MetricCard>
    </MetricCards>
  </div>
</template>
```

`label` names the card. `value` is the figure you want people to read. Both are display values: the component does not format currency, compact large numbers, or load analytics. Pass `128.4k` when that is the string you want on screen. A finite number is printed as its decimal form, and a positive numeric `delta` gains a leading `+`.

`delta` is optional. Omit it when the card is a level, not a change. `description` then sits under the value on its own, as with “Across 3 environments”. When `delta` is set, `description` sits beside the change.

The trend arrow follows `trend` when you pass it. Otherwise it follows the delta: a leading `+` or a positive number is up, a leading `-` (or the minus signs `−` and `–`) is down, and `0` or a value with no sign to read is neutral. `tone` chooses the color. Up defaults to a positive green and down defaults to a negative rose. Set `tone="positive"` when a downward delta is the good direction, as with an error rate. Color is not the only signal: the arrow and a visually hidden “Increased”, “Decreased”, or “No change” travel with the figure.

`MetricCards` is the row. `columns` accepts `1`, `2`, `3`, or `4`. Any other value uses the three-column layout. The group name defaults to “Metrics”; pass `label` when the row needs a more specific accessible name. `MetricDelta` is also exported when a custom `delta` slot still wants the same arrow.

```vue
<MetricCard label="Requests" value="128.4k">
  <template #delta>
    <MetricDelta delta="+18.6%" description="from last week" />
  </template>
</MetricCard>
```

The `delta` slot replaces the whole footer row, including `description`. The `value` slot replaces the displayed figure. The `icon` slot replaces the `icon` prop. Icons are decorative.

## Accessibility

Each card is an article named by its label. The value is text, so it is available to assistive tech without an extra label. A delta icon is hidden from the accessibility tree. The direction is a visually hidden word placed before the figure, so the change is not announced as a bare percentage. A card with no delta does not invent a trend. `MetricCards` is a group. Its accessible name is the `label` prop.

The preview’s period control is a separate button group with `aria-pressed`. The card grid is a polite live region in that preview, so a period change announces the new figures. Add that live region in your page when the numbers update in place. The component does not add it for you.

## Props

### MetricCard

| Name        | Type                                    | Default | Description                                                        |
| :---------- | :-------------------------------------- | :------ | :----------------------------------------------------------------- |
| label       | `string`                                | —       | Name of the metric                                                 |
| value       | `string \| number`                      | —       | Figure to display                                                  |
| delta       | `string \| number`                      | —       | Change. Omit it when there is no trend                             |
| trend       | `'up' \| 'down' \| 'neutral'`           | —       | Arrow direction. Inferred from `delta` when omitted                |
| tone        | `'positive' \| 'negative' \| 'neutral'` | —       | Color. Up is positive and down is negative when omitted            |
| description | `string`                                | —       | Caption beside the delta, or under the value when delta is omitted |
| icon        | `Component`                             | —       | Decorative icon. The `icon` slot replaces it                       |
| class       | `HTMLAttributes['class']`               | —       | Card classes                                                       |

### MetricCards

| Name    | Type                      | Default   | Description                                           |
| :------ | :------------------------ | :-------- | :---------------------------------------------------- |
| label   | `string`                  | `Metrics` | Accessible name of the group                          |
| columns | `number`                  | `3`       | `1`, `2`, `3`, or `4`. Any other value uses 3 columns |
| class   | `HTMLAttributes['class']` | —         | Group classes                                         |

### MetricDelta

| Name        | Type                                    | Default | Description                                       |
| :---------- | :-------------------------------------- | :------ | :------------------------------------------------ |
| delta       | `string \| number`                      | —       | Change to display. An empty delta renders nothing |
| trend       | `'up' \| 'down' \| 'neutral'`           | —       | Arrow direction                                   |
| tone        | `'positive' \| 'negative' \| 'neutral'` | —       | Color                                             |
| description | `string`                                | —       | Caption. The default slot replaces it             |
| class       | `HTMLAttributes['class']`               | —       | Row classes                                       |

## Slots

### MetricCard

| Name  | Description                                    |
| :---- | :--------------------------------------------- |
| icon  | Replaces the decorative icon                   |
| value | Replaces the displayed figure                  |
| delta | Replaces the footer row, including the caption |

### MetricCards

| Name    | Description      |
| :------ | :--------------- |
| default | The metric cards |

### MetricDelta

| Name    | Description          |
| :------ | :------------------- |
| default | Replaces the caption |

`formatMetricValue`, `formatMetricDelta`, `hasMetricDelta`, `resolveMetricTrend`, `resolveMetricTone`, `metricDirectionLabel`, `metricColumnClass`, and `metricToneClass` are exported from the same entry.
