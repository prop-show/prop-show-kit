## Source

This block is a Vue port of **CTA Two** from [Svelte Efferd](https://sv-efferd.pages.dev/blocks/cta), created by [SikandarJODD](https://github.com/SikandarJODD). See the [original source repository](https://github.com/SikandarJODD/sv-efferd). The port preserves the original layout and visual treatments while adapting it to Vue and shadcn-vue.

## Usage

`CtaCentered` accepts `title`, `primaryLabel`, and `secondaryLabel` props. It also accepts `description`. Handle `@start` and `@contact`, or replace the `actions` slot with your own links.

```vue
<script setup lang="ts">
import CtaCentered from "@/components/cta/CtaCentered.vue";
import { Button } from "@/components/ui/button";
</script>

<template>
  <CtaCentered>
    <template #actions>
      <Button variant="secondary" as-child><a href="/contact">Contact Sales</a></Button>
      <Button as-child><a href="/signup">Get Started</a></Button>
    </template>
  </CtaCentered>
</template>
```
