> Five responsive call-to-action blocks, each with its own preview, source code and install command.

- [Split CTA](/blocks/cta/cta-split): A compact split layout with full-width dividers.
- [Centered CTA](/blocks/cta/cta-centered): A centered heading with a muted action band.
- [Corner Accent CTA](/blocks/cta/cta-corner-accent): An editorial layout with extended borders and four corner marks.
- [Trial Card CTA](/blocks/cta/cta-trial-card): A rounded card with trial reassurance.
- [Newsletter CTA](/blocks/cta/cta-newsletter): An email form with native validation and overlapping avatars.

## Source

All five blocks in this collection are Vue ports of **CTA One–Five** from [Svelte Efferd](https://sv-efferd.pages.dev/blocks/cta), created by [SikandarJODD](https://github.com/SikandarJODD). The original Svelte implementations are available in the [sv-efferd source repository](https://github.com/SikandarJODD/sv-efferd).

PropShow Kit preserves the original layouts and visual treatments while adapting the components to Vue and shadcn-vue. This port adds configurable copy, action events and slots, plus email validation and a submission event for the newsletter form.
