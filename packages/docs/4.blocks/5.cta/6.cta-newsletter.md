## Source

This block is a Vue port of **CTA Five** from [Svelte Efferd](https://sv-efferd.pages.dev/blocks/cta), created by [SikandarJODD](https://github.com/SikandarJODD). See the [original source repository](https://github.com/SikandarJODD/sv-efferd). The port preserves the original layout and visual treatments while adapting it to Vue and shadcn-vue.

## Usage

`CtaNewsletter` accepts `title`, `description`, and `pending`. Connect `@subscribe` to your newsletter service; the event provides the trimmed email address. Set `pending` during the request and use the `status` slot for success or error feedback.

The preview demonstrates submission; it does not send or store email addresses.

The newsletter avatars use the same external Unsplash images as the reference. Replace them with your own team photos when shipping.
