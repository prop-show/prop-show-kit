# Blocks

> Ready screens for a shadcn-vue project. 4 blocks. A component fills one gap; a block installs a section you then edit.

PropShow Kit is an add-on registry, not a replacement UI library. shadcn-vue still supplies the primitives. Install a block with the same CLI you use for a component:

```bash
npx shadcn-vue@latest add https://kit.prop.show/r/project-overview.json
```

After you register `@propshow` in `components.json`, the short form is `npx shadcn-vue@latest add @propshow/project-overview`. See [The @propshow registry](/guide/registry) and [Components and blocks](/guide/components-and-blocks).

## Workspace

工作台 — three app screens. They keep sample data in memory so you can click through the preview, then connect your own requests.

- [Project overview](/blocks/project-overview) — metric cards, deployment status, and a reporting-period switch.
- [Team members](/blocks/team-members) — search, member status, an empty state, and an invitation dialog.
- [Workspace settings](/blocks/workspace-settings) — notification preferences, unsaved-change feedback, save, and discard.

[Workspace collection](/blocks/workspace)

## Privacy

A banner and a preference dialog. The choice stays in memory until you persist it. The block does not write a browser cookie.

- [Cookie consent](/blocks/cookie-consent) — accept all, reject optional cookies, or save categories. Necessary cookies stay on.
