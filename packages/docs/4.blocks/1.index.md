# Blocks

> Ready screens for a shadcn-vue project. 36 blocks. A component fills one gap; a block installs a section or a workspace you then edit.

PropShow Kit is an add-on registry, not a replacement UI library. shadcn-vue still supplies the primitives. Install a block with the same CLI you use for a component:

```bash
npx shadcn-vue@latest add https://kit.prop.show/r/hero-spotlight.json
```

After you register `@propshow` in `components.json`, the short form is `npx shadcn-vue@latest add @propshow/hero-spotlight`. See [The @propshow registry](/guide/registry) and [Components and blocks](/guide/components-and-blocks).
