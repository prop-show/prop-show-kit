## Source

This block is a Vue port of **Logo Cloud Three** from [Svelte Efferd](https://sv-efferd.pages.dev/blocks/logo-cloud), created by [SikandarJODD](https://github.com/SikandarJODD). See the [original source repository](https://github.com/SikandarJODD/sv-efferd). The port preserves the original layout and visual treatments while adapting it to Vue and shadcn-vue.

## Usage

Pass `logos` as an array of `{ src, alt }` objects to replace the demonstration brands. Dark mode displays white wordmarks. Hover to pause, or use the keyboard-accessible pause/resume button. Each repeated group fills the container even with a short logo list. Reduced-motion preferences stop the animation and allow horizontal scrolling. Default brands demonstrate the layout and do not imply an endorsement or partnership.

```vue
<script setup lang="ts">
import LogoCloudMarquee from "@/components/logo-cloud/LogoCloudMarquee.vue";

const logos = [
  { src: "/logos/acme.svg", alt: "Acme" },
  { src: "/logos/example.svg", alt: "Example" },
];
</script>

<template>
  <LogoCloudMarquee :logos="logos" />
</template>
```
