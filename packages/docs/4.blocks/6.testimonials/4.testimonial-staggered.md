## Source

This block is a Vue port of **Testimonial Three** from [Svelte Efferd](https://sv-efferd.pages.dev/blocks/testimonials), created by [SikandarJODD](https://github.com/SikandarJODD). See the [original source repository](https://github.com/SikandarJODD/sv-efferd). The port preserves the original layout and visual treatments while adapting it to Vue and shadcn-vue.

The default quotes are fictional, humorous demonstration content from the original source, not actual endorsements. Replace them with your own verified testimonials before publishing.

## Usage

Pass a `testimonials` array containing `quote`, `name`, `role`, optional `company`, and optional `image`. The scoped `quote` slot exposes `testimonial`.

```vue
<script setup lang="ts">
import TestimonialStaggered from "@/components/testimonials/TestimonialStaggered.vue";
</script>

<template>
  <TestimonialStaggered
    :testimonials="[
      { quote: 'The setup was straightforward.', name: 'Alex Chen', role: 'Product designer' },
    ]"
  />
</template>
```
