## Source

This block is a Vue port of **Testimonial Four** from [Svelte Efferd](https://sv-efferd.pages.dev/blocks/testimonials), created by [SikandarJODD](https://github.com/SikandarJODD). See the [original source repository](https://github.com/SikandarJODD/sv-efferd). The port preserves the original layout and visual treatments while adapting it to Vue and shadcn-vue.

The default quotes are fictional, humorous demonstration content from the original source, not actual endorsements. Replace them with your own verified testimonials before publishing.

## Usage

Pass a `testimonials` array containing `quote`, `name`, `role`, and optional `company`. The first two entries form the left column; remaining entries form the right column. Use three entries to reproduce the original composition. The scoped `quote` slot exposes `testimonial`.

```vue
<script setup lang="ts">
import TestimonialSplitGrid from "@/components/testimonials/TestimonialSplitGrid.vue";
</script>

<template>
  <TestimonialSplitGrid
    :testimonials="[
      { quote: 'The setup was straightforward.', name: 'Alex Chen', role: 'Product designer' },
      { quote: 'The components fit our workflow.', name: 'Jordan Lee', role: 'Developer' },
      { quote: 'We shipped our first page quickly.', name: 'Casey Kim', role: 'Founder' },
    ]"
  />
</template>
```
