## Source

This block is a Vue port of **Testimonial One** from [Svelte Efferd](https://sv-efferd.pages.dev/blocks/testimonials), created by [SikandarJODD](https://github.com/SikandarJODD). See the [original source repository](https://github.com/SikandarJODD/sv-efferd). The port preserves the original layout and visual treatments while adapting it to Vue and shadcn-vue.

The default quotes are fictional, humorous demonstration content from the original source, not actual endorsements. Replace them with your own verified testimonials before publishing.

## Usage

Pass `quote`, `name`, `role`, and `image` to replace the demonstration content. The `quote` slot supports rich text. Use `company` or the `company` slot to replace the company mark.

```vue
<script setup lang="ts">
import TestimonialCentered from "@/components/testimonials/TestimonialCentered.vue";
</script>

<template>
  <TestimonialCentered
    quote="The setup was straightforward."
    name="Alex Chen"
    role="Product designer"
  />
</template>
```
