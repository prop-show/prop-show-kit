## Source

This block is a Vue port of **Integration Four** from [Svelte Efferd](https://sv-efferd.pages.dev/blocks/integrations), created by [SikandarJODD](https://github.com/SikandarJODD). See the [original source repository](https://github.com/SikandarJODD/sv-efferd). The port preserves the original layout and visual treatments while adapting it to Vue and shadcn-vue.

## Usage

Pass `title`, `description`, and `tiles` to replace the heading and grid-positioned logos. Each tile has a `row`, `col`, and optional `logo` with `src`, `alt`, and optional `isInvertable`. Set `href` and `actionLabel` for the link, or use the `actions` slot for a custom action. The original has no action; set `actionLabel` to display one.

```vue
<script setup lang="ts">
import IntegrationsFloating from "@/components/integrations/IntegrationsFloating.vue";
</script>

<template>
  <IntegrationsFloating />
</template>
```

The default content is illustrative. Replace demonstration copy and logo URLs before publishing; the defaults load logos from `storage.efferd.com`.
