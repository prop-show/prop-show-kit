## Source

This block is a Vue port of **Integration One** from [Svelte Efferd](https://sv-efferd.pages.dev/blocks/integrations), created by [SikandarJODD](https://github.com/SikandarJODD). See the [original source repository](https://github.com/SikandarJODD/sv-efferd). The port preserves the original layout and visual treatments while adapting it to Vue and shadcn-vue.

## Usage

Pass `integrations` to replace the logo URLs, names, descriptions, and optional `isInvertable` dark-mode treatment. Set `href` and `actionLabel` for the link, or use the `actions` slot for a custom action.

```vue
<script setup lang="ts">
import IntegrationsStrip from "@/components/integrations/IntegrationsStrip.vue";
</script>

<template>
  <IntegrationsStrip />
</template>
```

The default content is illustrative. Replace demonstration copy and logo URLs before publishing; the defaults load logos from `storage.efferd.com`.
