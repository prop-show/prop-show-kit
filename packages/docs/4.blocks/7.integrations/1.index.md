Five independent blocks. Install the layout you need and replace its demonstration content.

- [Strip](/blocks/integrations/integrations-strip): A compact integration strip with lightweight cards and a link-out action.
- [Grid](/blocks/integrations/integrations-grid): A framed integration grid with decorative corner accents.
- [Split](/blocks/integrations/integrations-split): A split integration hero with grid-positioned logos and divider rails.
- [Floating](/blocks/integrations/integrations-floating): A large product statement beside a grid of floating logo tiles.
- [Cluster](/blocks/integrations/integrations-cluster): Overlapping logo pills with a centered heading and primary action.
