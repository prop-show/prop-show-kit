> A cookie banner and a preference dialog for accepting cookies by category.

The choice stays in component state. This block does not write a browser cookie or call a consent vendor. Persist `v-model` in your app, and replace the sample categories and policy link.

::cookie-consent-preview
::

## Usage

```vue
<script setup lang="ts">
import { shallowRef, watch } from "vue";
import { CookieConsent, parseConsent, serializeConsent } from "@/components/cookie-consent";
import type { CookieConsentState } from "@/components/cookie-consent";

const storageKey = "cookie-consent";
const consent = shallowRef<CookieConsentState | undefined>(
  parseConsent(localStorage.getItem(storageKey)),
);

watch(consent, (value) => {
  if (!value || value.status === "unknown") localStorage.removeItem(storageKey);
  else localStorage.setItem(storageKey, serializeConsent(value));
});
</script>

<template>
  <CookieConsent v-model="consent" policy-href="/privacy" />
</template>
```

`v-model` is the current choice. Omit it and the banner stays undecided until this page chooses. `status` is `unknown`, `accepted`, `rejected`, or `custom`. Necessary categories are always on. Optional categories stay off until accept-all or a saved selection turns them on.

`parseConsent` and `serializeConsent` only translate JSON. Wiring them to `localStorage`, as above, is one way to remember the choice. A real cookie belongs in your app.

The policy link renders only when `policyHref` is a hash (`#privacy`), a same-site path (`/privacy`), or an `http` / `https` URL. `javascript:` and protocol-relative links are dropped.

## Accessibility

The banner is a region named “Cookie consent”. Reject, preferences, and accept are buttons, and reject is as easy to reach as accept. The preference dialog traps focus, labels itself, and closes from the close button or Escape without saving the draft. Each category is a switch named by its title. Necessary switches stay on and expose “Always on”. A polite live region announces the choice after accept, reject, or save.

## Props

| Name                   | Type                      | Default                                                                                            | Description                                 |
| :--------------------- | :------------------------ | :------------------------------------------------------------------------------------------------- | :------------------------------------------ |
| modelValue             | `CookieConsentState`      | undecided                                                                                          | Current choice (`v-model`)                  |
| categories             | `CookieCategory[]`        | Necessary, Analytics, Marketing                                                                    | Categories. `required` stays on             |
| title                  | `string`                  | `We use cookies`                                                                                   | Banner title                                |
| description            | `string`                  | `Necessary cookies keep this site working. Analytics and marketing stay off until you allow them.` | Banner text                                 |
| policyHref             | `string`                  | —                                                                                                  | Policy link. Unsafe values are not rendered |
| policyLabel            | `string`                  | `Cookie policy`                                                                                    | Policy link text                            |
| acceptAllLabel         | `string`                  | `Accept all`                                                                                       | Accept action                               |
| rejectLabel            | `string`                  | `Reject optional`                                                                                  | Reject action                               |
| preferencesLabel       | `string`                  | `Preferences`                                                                                      | Opens the dialog from the banner            |
| saveLabel              | `string`                  | `Save preferences`                                                                                 | Saves the dialog draft                      |
| settingsLabel          | `string`                  | `Cookie settings`                                                                                  | Reopens preferences after a choice          |
| necessaryLabel         | `string`                  | `Always on`                                                                                        | Shown beside a required category            |
| preferencesTitle       | `string`                  | `Cookie preferences`                                                                               | Dialog title                                |
| preferencesDescription | `string`                  | `Choose which categories this browser may store. Necessary cookies stay on.`                       | Dialog description                          |
| closeLabel             | `string`                  | `Close preferences`                                                                                | Close button name                           |
| acceptedMessage        | `string`                  | `All cookie categories accepted.`                                                                  | Live region after accept all                |
| rejectedMessage        | `string`                  | `Optional cookies rejected. Necessary cookies stay on.`                                            | Live region after reject                    |
| savedMessage           | `string`                  | `Cookie preferences saved.`                                                                        | Live region after save                      |
| class                  | `HTMLAttributes['class']` | —                                                                                                  | Banner classes                              |

`CookieCategory` is `{ id, title, description, required? }`. Ids must be unique and non-empty. A blank or repeated id is dropped.

## Events

| Name              | Payload              | Description                                     |
| :---------------- | :------------------- | :---------------------------------------------- |
| update:modelValue | `CookieConsentState` | Next choice                                     |
| accept            | `CookieConsentState` | Accept all. Every listed category is on         |
| reject            | `CookieConsentState` | Optional categories are off. Necessary stays on |
| save              | `CookieConsentState` | Draft saved. Required categories stay on        |

`acceptAll`, `rejectOptional`, `savePreferences`, `normalizeConsent`, `unknownConsent`, and `isConsentDecided` are exported from the same entry if you need the same rules outside the banner.
