## Source

This block is a Vue port of **Feature One** from [Svelte Efferd](https://sv-efferd.pages.dev/blocks/features), created by [SikandarJODD](https://github.com/SikandarJODD) and licensed under MIT. See the [original source repository](https://github.com/SikandarJODD/sv-efferd). The port preserves the original composition while adapting it to Vue and shadcn-vue.

## Usage

Pass `features` to replace the feature list. Each item has a `title`, `description`, and `icon`; supply a Vue component for `icon`, such as an icon imported from `@lucide/vue`.

```vue
<script setup lang="ts">
import { Users, Zap } from "@lucide/vue";
import FeatureStrip from "@/components/features/FeatureStrip.vue";

const features = [
  {
    title: "Work together",
    description: "Keep your team connected in a shared workspace.",
    icon: Users,
  },
  {
    title: "Move faster",
    description: "Keep everyday tools close to your work.",
    icon: Zap,
  },
];
</script>

<template>
  <FeatureStrip :features="features" />
</template>
```

The default content preserves the original demonstration copy. Customize the feature titles, descriptions and icons for your product before publishing.
