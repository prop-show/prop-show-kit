Five independent blocks. Install the layout you need and replace its demonstration content.

- [Strip](/blocks/features/feature-strip): A compact strip of features with icons, titles and descriptions.
- [Framed](/blocks/features/feature-framed): A framed feature collection with a section title.
- [Rails](/blocks/features/feature-rails): A feature layout organized around decorative rails.
- [Cards](/blocks/features/feature-cards): A collection of feature cards with a section title and description.
- [Grid](/blocks/features/feature-grid): A feature grid with a section title and description.

## Source

All five blocks are Vue ports of **Feature One–Five** from [Svelte Efferd](https://sv-efferd.pages.dev/blocks/features), created by [SikandarJODD](https://github.com/SikandarJODD) and licensed under MIT. See the [original source repository](https://github.com/SikandarJODD/sv-efferd).

Every block accepts a `features` array of `{ title, description, icon }`, where `icon` is a Vue component. Framed also accepts `title`; Cards and Grid also accept `title` and `description` for the section heading.

The ports preserve the original demonstration copy. Replace it with your own product's features and verified claims before publishing.
