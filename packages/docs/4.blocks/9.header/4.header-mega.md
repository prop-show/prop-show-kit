## Source

Vue port of **Header Three** from [Svelte Efferd](https://sv-efferd.pages.dev/blocks/header), created by [SikandarJODD](https://github.com/SikandarJODD). See the [original source repository](https://github.com/SikandarJODD/sv-efferd). The original layout and scroll treatments are preserved, with Vue and Reka UI handling interaction. Source files retain the MIT license.

## Usage

```vue
<script setup lang="ts">
import HeaderMega from "@/components/header/HeaderMega.vue";
</script>

<template>
  <HeaderMega home-href="/" sign-in-href="/login" sign-up-href="/signup">
    <template #logo><span class="text-sm font-semibold">Acme</span></template>
  </HeaderMega>
</template>
```

`homeHref`, `homeLabel`, `signInHref`, and `signUpHref` configure the brand and account links. Replace the demonstration navigation in `header/navigation.ts` with your own destinations. The `logo` slot replaces the original brand mark. Mount the header directly in the page's scrolling container to enable sticky positioning.

The mobile menu supports keyboard focus, Escape to close, and closing after navigation. Desktop Product and Company menus also support keyboard navigation. Scroll transitions respect reduced-motion preferences.
