## Source

Vue port of **Header Four** from [Svelte Efferd](https://sv-efferd.pages.dev/blocks/header), created by [SikandarJODD](https://github.com/SikandarJODD). See the [original source repository](https://github.com/SikandarJODD/sv-efferd). The original layout and scroll treatments are preserved, with Vue and Reka UI handling interaction. Source files retain the MIT license.

## Usage

```vue
<script setup lang="ts">
import HeaderFloating from "@/components/header/HeaderFloating.vue";
</script>

<template>
  <HeaderFloating home-href="/" sign-in-href="/login" sign-up-href="/signup">
    <template #logo><span class="text-sm font-semibold">Acme</span></template>
  </HeaderFloating>
</template>
```

`homeHref`, `homeLabel`, `signInHref`, and `signUpHref` configure the brand and account links. Replace the demonstration navigation in `header/navigation.ts` with your own destinations. The `logo` slot replaces the original brand mark. Mount the header directly in the page's scrolling container to enable sticky positioning.

The mobile menu supports keyboard focus, Escape to close, and closing after navigation. Scroll transitions respect reduced-motion preferences.
