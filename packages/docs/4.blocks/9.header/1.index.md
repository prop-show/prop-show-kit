Five independently installable navigation blocks, each with a sticky header, account links, and an accessible mobile menu.

- [Simple](/blocks/header/header-simple): A clean sticky header with simple nav links and a compact mobile menu.
- [Framed](/blocks/header/header-framed): A framed sticky header that narrows into a softer product shell on scroll.
- [Mega](/blocks/header/header-mega): A sticky header with two-column mega menus and a full mobile navigation.
- [Floating](/blocks/header/header-floating): A floating rounded header with prominent account actions.
- [Pill](/blocks/header/header-pill): A rounded header with compact mega menus and pill-shaped account actions.

Each installer includes its required helpers under `components/header`. Navigation data is shared when multiple header layouts are installed. Edit `navigation.ts` to set your routes and replace the default logo through the `logo` slot. Demonstration links and account routes must be connected to your application.
