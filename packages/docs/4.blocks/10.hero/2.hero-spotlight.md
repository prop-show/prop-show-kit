## Source

This block is a Vue port of **Hero One** from [Svelte Efferd](https://sv-efferd.pages.dev/blocks/hero), created by [SikandarJODD](https://github.com/SikandarJODD). It preserves the original composition while adapting it to Vue and shadcn-vue, reusing the existing Header and Logo Cloud blocks. The original MIT notice is retained in the source.

## Usage

`HeroSpotlight` accepts `title`, `description`, `announcement`, `announcementHref`, `primaryLabel`, and `secondaryLabel`. Handle `@start` and `@contact`, or replace the `actions` slot with links. The `header` and `logos` slots replace the navigation and brand collection.

```vue
<script setup lang="ts">
import HeroSpotlight from "@/components/hero/HeroSpotlight.vue";
import { Button } from "@/components/ui/button";
</script>

<template>
  <HeroSpotlight>
    <template #actions>
      <Button variant="outline" as-child><a href="/contact">Book a Call</a></Button>
      <Button as-child><a href="/signup">Get started</a></Button>
    </template>
  </HeroSpotlight>
</template>
```

The default announcements, dashboard screenshots and brand logos reproduce the reference demo. Replace them with your own content before publishing. Default action buttons emit events; the example above supplies navigation links.
