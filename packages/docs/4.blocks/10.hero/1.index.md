> Three complete responsive hero blocks, each with navigation, a trust section, preview, source code and install command.

- [Spotlight Hero](/blocks/hero/hero-spotlight): A centered editorial layout with subtle rails and a marquee trust band.
- [Framed Hero](/blocks/hero/hero-framed): A bordered product layout with corner accents and a dashboard preview.
- [Product Hero](/blocks/hero/hero-product): A left-aligned heading, fading dashboard mockup and compact logo collection.

## Source

These blocks are Vue ports of **Hero One–Three** from [Svelte Efferd](https://sv-efferd.pages.dev/blocks/hero), created by [SikandarJODD](https://github.com/SikandarJODD). Original MIT notices are retained in the component sources.

Each block composes the existing Header and Logo Cloud components. The registry installs these dependencies automatically. The ports provide configurable copy, action events and slots, responsive layouts and light/dark themes. Product screenshots and default logos use the original external assets at `storage.efferd.com`.
