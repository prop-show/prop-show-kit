# Tabs

> Switch between related panels using the pointer or arrow keys.

::ui-sdk-tabs-preview
::

## Install

:registry-install{url="/r/ui-sdk-tabs.json"}

## Usage

```vue
<script setup lang="ts">
import { Tabs, TabsContent, TabsList, TabsTrigger } from "@/components/ui/ui-sdk-tabs";
</script>

<template>
  <Tabs default-value="overview" class="flex flex-col gap-2">
    <TabsList aria-label="Project">
      <TabsTrigger value="overview">Overview</TabsTrigger>
      <TabsTrigger value="activity">Activity</TabsTrigger>
    </TabsList>
    <TabsContent value="overview">The latest deployment is ready.</TabsContent>
    <TabsContent value="activity">The main branch was deployed.</TabsContent>
  </Tabs>
</template>
```

Match each trigger's `value` to its panel. Use `v-model` for a controlled selection, `orientation="vertical"` for a vertical list, or `activation="manual"` to move focus with arrow keys and select with Enter or Space. `Tabs` and `TabsContent` are exported directly from UI SDK. Style the panel where you use it.
