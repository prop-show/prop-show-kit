# Collapsible

> Show and hide a panel with a keyboard-accessible trigger.

::ui-sdk-collapsible-preview
::

## Install

:registry-install{url="/r/ui-sdk-collapsible.json"}

## Usage

```vue
<script setup lang="ts">
import { Button } from "@/components/ui/button";
import {
  Collapsible,
  CollapsibleContent,
  CollapsibleTrigger,
} from "@/components/ui/ui-sdk/collapsible";
</script>

<template>
  <Collapsible class="space-y-2">
    <CollapsibleTrigger>
      <template #render="{ props }">
        <Button v-bind="props" variant="outline">Delivery details</Button>
      </template>
    </CollapsibleTrigger>
    <CollapsibleContent>Daily digests arrive at 9:00 AM.</CollapsibleContent>
  </Collapsible>
</template>
```

Use `v-model` to control whether the panel is open or `default-open` to start open. `keep-mounted` on `CollapsibleContent` preserves its state while hidden. To use your own button, pass the trigger's `#render` props to the button.

The trigger and panel leave styling to the caller, following [shadcn-vue Collapsible](https://www.shadcn-vue.com/docs/components/collapsible.html). The entry exports the UI SDK parts directly.
