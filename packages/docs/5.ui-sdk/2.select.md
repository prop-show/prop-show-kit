# Select

> Choose from a list with keyboard navigation, typeahead, and a selected-item indicator.

::ui-sdk-select-preview
::

## Install

:registry-install{url="/r/ui-sdk-select.json"}

## Usage

```vue
<script setup lang="ts">
import {
  Select,
  SelectContent,
  SelectGroup,
  SelectGroupLabel,
  SelectItem,
  SelectSeparator,
  SelectTrigger,
  SelectValue,
} from "@/components/ui/ui-sdk-select";
</script>

<template>
  <Select default-value="viewer" virtual-focus>
    <SelectTrigger class="w-48" aria-label="Project access">
      <SelectValue placeholder="Choose access" />
    </SelectTrigger>
    <SelectContent>
      <SelectGroup>
        <SelectGroupLabel>Project access</SelectGroupLabel>
        <SelectItem value="viewer">Viewer</SelectItem>
        <SelectItem value="editor">Editor</SelectItem>
      </SelectGroup>
      <SelectSeparator />
      <SelectItem value="admin" disabled>Admin</SelectItem>
    </SelectContent>
  </Select>
</template>
```

Use `v-model` for controlled state, `default-value` for the initial value, and `name` to include the selection in a form. Use `size="sm"` on `SelectTrigger` for the compact height. Use `SelectGroupLabel` to label an option group. To name the trigger, use `aria-label`, `aria-labelledby`, or `SelectLabel`.

`SelectContent` accepts `side`, `align`, `side-offset`, and `align-item-with-trigger`. The option list scrolls natively. `virtual-focus` keeps keyboard focus on the trigger while you browse the options.

The control sizes and styles follow [shadcn-vue New York Select](https://www.shadcn-vue.com/docs/components/select.html).
