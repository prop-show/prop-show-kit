# Checkbox

> Check a single option or group several options under a parent checkbox.

::ui-sdk-checkbox-preview
::

## Install

:registry-install{url="/r/ui-sdk-checkbox.json"}

## Usage

```vue
<script setup lang="ts">
import { ref, useId } from "vue";
import { Checkbox, type CheckedState } from "@/components/ui/ui-sdk-checkbox";

const id = useId();
const checked = ref<CheckedState>(false);
</script>

<template>
  <label :for="id">
    <Checkbox :id="id" v-model="checked" name="email-updates" />
    Email updates
  </label>
</template>
```

Use `default-checked` for an uncontrolled checkbox. Pass `"indeterminate"` for the mixed state, or let `CheckboxGroup` compute it for a checkbox with `parent`. Pass `all-values` to the group so the parent knows which options to select. The default slot exposes `checked` and can replace the indicator icon.
