# Switch

> Toggle a setting with pointer or keyboard input. A named switch participates in forms.

::ui-sdk-switch-preview
::

## Install

:registry-install{url="/r/ui-sdk-switch.json"}

## Usage

```vue
<script setup lang="ts">
import { ref, useId } from "vue";
import { Switch } from "@/components/ui/ui-sdk-switch";

const enabled = ref(true);
const id = useId();
</script>

<template>
  <label :for="id">Desktop alerts</label>
  <Switch :id="id" v-model="enabled" name="desktop-alerts" />
</template>
```

Use `v-model` for controlled state or `default-value` to start checked. `default-checked` is also accepted. The optional `thumb` slot customizes the thumb. A form submits the switch's `value` when checked. Use a label or `aria-label` to name the setting.

The track, thumb, and focus styles follow [shadcn-vue New York Switch](https://www.shadcn-vue.com/docs/components/switch.html).
