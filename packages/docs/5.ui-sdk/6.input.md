# Input

> A text input with native HTML constraints and Vue model binding.

::ui-sdk-input-preview
::

## Install

:registry-install{url="/r/ui-sdk-input.json"}

## Usage

```vue
<script setup lang="ts">
import { ref, useId } from "vue";
import { Input } from "@/components/ui/ui-sdk-input";

const emailId = useId();
const email = ref("");
</script>

<template>
  <label :for="emailId">Email address</label>
  <Input :id="emailId" v-model="email" name="email" type="email" autocomplete="email" required />
</template>
```

Use `v-model` for a controlled string or `default-value` for an uncontrolled initial value. Pass native attributes such as `type`, `name`, `placeholder`, and `required` directly. Use `aria-invalid` for an error set by your application, or compose `Input` with the UI SDK `Field` to associate labels and validation messages.
