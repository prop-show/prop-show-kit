# Button

> Run an action with New York variants and sizes. A promise returned by the click handler keeps the button pending until it settles.

::ui-sdk-button-preview
::

## Install

:registry-install{url="/r/ui-sdk-button.json"}

## Usage

```vue
<script setup lang="ts">
import { Button } from "@/components/ui/ui-sdk-button";

async function save() {
  await new Promise((resolve) => setTimeout(resolve, 800));
}
</script>

<template>
  <Button v-slot="{ state }" @click="save">
    {{ state.pending ? "Saving…" : "Save changes" }}
  </Button>
  <Button variant="outline" size="sm">Cancel</Button>
</template>
```

Use `variant` for `default`, `secondary`, `outline`, `ghost`, `link`, or `destructive`. Use `size` for `default`, `xs`, `sm`, `lg`, `icon`, `icon-xs`, `icon-sm`, or `icon-lg`. Give icon-only buttons an accessible name. `buttonVariants` is exported from the same directory, and `class` overrides individual styles.

For async actions, pass a handler that returns its promise. Use `type="submit"` for form submission and manage pending state in the form's submit handler. To render your own element, bind the SDK's `#render` props to it and render the supplied `children` component.
