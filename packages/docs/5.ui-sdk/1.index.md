# UI SDK

> Vue components styled with shadcn-vue tokens and powered by [Vercel UI SDK](https://ui-sdk.dev/docs/vue).

Install each component with the shadcn-vue CLI. The entries use the `ui-sdk-` prefix or the `ui-sdk/` directory under your `ui` alias, so they can sit alongside your existing controls.
