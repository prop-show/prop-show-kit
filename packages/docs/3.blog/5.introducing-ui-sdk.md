# Introducing UI SDK in PropShow Kit

> Seven Vue controls bring Vercel UI SDK behavior to the kit's copy-and-paste registry.

The docs now have a UI SDK collection next to Components and Blocks. Each entry includes an interactive example, source files, and a shadcn-vue install command. The collection index uses the same SVG illustrations as the component catalog. [Browse UI SDK](/ui-sdk).

## Why we added UI SDK

A select needs to handle keys, focus, and selection while its list is open. A checkbox group needs to keep the parent state in sync when only some options are checked. These behaviors should work the same way when you change a control's appearance. Vercel UI SDK gives us Vue primitives that handle those interactions and expose the state the styles need. [Vercel UI SDK for Vue](https://ui-sdk.dev/docs/vue).

PropShow Kit uses shadcn-vue's New York styles and theme tokens for the parts that need a default appearance. Button exposes variants and sizes, and Select lets you style the trigger or replace the selected-item icon. For parts that work without a styled wrapper, the registry exports the SDK primitives directly. Collapsible is a single TypeScript file, and Tabs exports its root and content directly while styling the list and triggers.

## What you can try

- **Start with a form.** Run the simulated save action to see Button's pending state, validate an email address in Input, or click the parent checkbox to switch the whole group. [Button](/ui-sdk/button) · [Input](/ui-sdk/input) · [Checkbox](/ui-sdk/checkbox)
- **Choose a value.** Type to find an option in Select, or use Space to toggle Switch. [Select](/ui-sdk/select) · [Switch](/ui-sdk/switch)
- **Explore disclosure and navigation.** Open the Collapsible details or use the arrow keys to move between tab panels. [Collapsible](/ui-sdk/collapsible) · [Tabs](/ui-sdk/tabs)

## Install a component

In an existing shadcn-vue project, try Button first.

```bash
npx shadcn-vue@latest add https://kit.prop.show/r/ui-sdk-button.json
```

The CLI copies the Vue source and installs the declared runtime dependencies, including `@ui-sdk/vue` and its matching `@ui-sdk/core` package. With the default UI alias, import Button from `@/components/ui/ui-sdk-button`. Its directory can sit alongside an existing `@/components/ui/button`. If you already registered `@propshow`, you can use `npx shadcn-vue@latest add @propshow/ui-sdk-button`. [Read the registry guide](/guide/registry).
