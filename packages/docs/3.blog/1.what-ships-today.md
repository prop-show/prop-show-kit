# What PropShow Kit ships today

> A tour of the current site: the guide, the four components in the registry, and how they get into your project.

PropShow Kit is two things right now: an **add-on** to **[Shadcn Vue](https://www.shadcn-vue.com/)** — a companion registry for the components the base library does not cover — and the docs site you are reading.

## Copied, not installed

There is no `npm install`. Each component is published as a registry entry, so the `shadcn-vue` CLI writes the source into your project next to everything it depends on — npm packages and shadcn-vue primitives alike. After that it is your file: read it, change it, version it.

## The guide

- **[Quick Start](/guide)** — the whole flow in four steps: choose a component, install it, use it, customize it.
- **[Introduction](/guide/introduction)** — what the kit is, why it is an add-on rather than a fork, and the design philosophy it shares with Shadcn Vue.

## The components

Four components are documented today, all built on Tailwind tokens and shadcn-vue primitives:

- **[Inline Tip](/components/inline-tip)** — a compact inline callout with `info`, `warning`, `success` and `error` variants.
- **[Copy](/components/copy)** — an accessible copy button with clipboard feedback and tooltip text.
- **[Status Badge](/components/status-badge)** — a badge with an animated status dot in six colors.
- **[Filters](/components/filters)** — a controlled list of field filters with keyboard navigation, validation and async options.

Every page follows the same shape: a live preview, the install command, a usage example, the full component source, and the props and slots tables.

## Install one

```bash
npx shadcn-vue@latest add https://kit.prop.show/r/inline-tip.json
```

Or register the kit once in your `components.json` and install by name:

```json
{
  "registries": {
    "@propshow": "https://kit.prop.show/r/{name}.json"
  }
}
```

```bash
npx shadcn-vue@latest add @propshow/filters
```
