# What PropShow Kit ships today

> A tour of the current site: the guide, 13 components, 36 blocks, and how they get into your project.

PropShow Kit is an **add-on registry** for **[Shadcn Vue](https://www.shadcn-vue.com/)** — the companion for what the base library does not cover — and the docs site you are reading. It is not a replacement UI library. shadcn-vue stays the source of primitives, tokens, and the CLI.

Two kinds of entries share that registry. **Components** fill a single gap. **Blocks** install a ready screen.

## Copied, not installed

There is no `npm install`. Each component and each block is a registry entry, so the `shadcn-vue` CLI writes the source into your project next to everything it depends on — npm packages and shadcn-vue primitives alike. After that it is your file: read it, change it, version it.

## The components

Thirteen components are documented, all built on Tailwind tokens and shadcn-vue primitives. The [index](/components) is the list to browse.

- **[Frame](/components/frame)**, **[Layer Card](/components/layer-card)**, **[Layer Dialog](/components/layer-dialog)** — panels, layered cards, and dialogs with a persistent title.
- **[Inline Tip](/components/inline-tip)**, **[Status Badge](/components/status-badge)**, **[Copy](/components/copy)**, **[Inline Copy Text](/components/inline-copy-text)** — callouts, status dots, and copy controls.
- **[Filters](/components/filters)**, **[Slider](/components/slider)** — field filters with keyboard navigation, and a range with value badges.
- **[Delete Resource](/components/delete-resource)** — a deletion dialog with typed confirmation.
- **[Pricing Plan](/components/pricing-plan)**, **[Pricing Plans](/components/pricing-plans)**, **[Pricing Table](/components/pricing-table)** — one plan, a set of plans, and a comparison table.

Every component page has a live preview, the install command, a usage example, the source, and the props and slots tables.

## The blocks

Thirty-six blocks are grouped on the [blocks index](/blocks). A block is a section or a screen, installed with the same command as a component.

- **[Hero](/blocks/hero)**, **[Call to Action](/blocks/cta)**, **[Header](/blocks/header)** — marketing chrome: three heroes, five CTAs, five headers.
- **[Workspace](/blocks/workspace)** (工作台) — [project overview](/blocks/project-overview), [team members](/blocks/team-members), and [workspace settings](/blocks/workspace-settings).
- **[Features](/blocks/features)**, **[Testimonials](/blocks/testimonials)**, **[Integrations](/blocks/integrations)**, **[Logo Cloud](/blocks/logo-cloud)** — five blocks in each group.

Block pages include a resizable preview. Sample quotes, logos, navigation links, and in-memory workspace data are there for the demo. Replace them before you publish. [Common pitfalls](/guide/pitfalls) lists the usual leftovers.

## Install one

A component:

```bash
npx shadcn-vue@latest add https://kit.prop.show/r/frame.json
```

A block:

```bash
npx shadcn-vue@latest add https://kit.prop.show/r/hero-spotlight.json
```

Or register the kit once in your `components.json` and install by name:

```json
{
  "registries": {
    "@propshow": "https://kit.prop.show/r/{name}.json"
  }
}
```

```bash
npx shadcn-vue@latest add @propshow/pricing-plan
npx shadcn-vue@latest add @propshow/workspace-settings
```
