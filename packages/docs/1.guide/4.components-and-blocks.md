# Components and blocks

> Components fill gaps in shadcn-vue. Blocks deliver a ready screen. Both are entries in the same add-on registry, installed with the same CLI.

PropShow Kit does not replace shadcn-vue. The base library still owns buttons, inputs, dialogs, and the rest of the primitive set. This registry adds what a product UI usually needs next, in two shapes.

## Components

A component is one focused piece with its own props and slots. You drop it into a page you are already building.

Fourteen components are documented:

- **Frame, Layer Card, Layer Dialog** — panels, layered cards, and dialogs with a persistent title.
- **Inline Tip, Status Badge, Copy, Inline Copy Text** — callouts, status dots, and copy controls.
- **Filters, Slider** — field filters with keyboard navigation, and a range control with value badges.
- **Delete Resource** — a deletion dialog with typed confirmation.
- **Notification Center** — an inbox panel with unread state, mark read, and an empty state.
- **Pricing Plan, Pricing Plans, Pricing Table** — a single plan, a set of plans, and a comparison table.

Start at the [component index](/components). Each page has a preview, the install command, the source, and the props and slots that were copied in.

Reach for a component when the surrounding layout is already yours and you are missing one control.

## Blocks

A block is a composed screen or section: several files, sample copy, and a layout you can resize in the docs before you install it. You edit that copy after install. The block is a starting screen, not a locked template.

Three blocks are grouped on the [block index](/blocks):

| Group              | What it is                           | Open                                   |
| ------------------ | ------------------------------------ | -------------------------------------- |
| Workspace (工作台) | Overview, team, and settings screens | [/blocks/workspace](/blocks/workspace) |

Reach for a block when you want the screen already assembled. A workspace block is the faster path to an overview, a team directory, or a settings form.

## They install the same way

```bash
npx shadcn-vue@latest add https://kit.prop.show/r/pricing-plan.json
npx shadcn-vue@latest add https://kit.prop.show/r/project-overview.json
```

With the [`@propshow` alias](/guide/registry) registered, those two commands are `@propshow/pricing-plan` and `@propshow/project-overview`.

A block can depend on components from this registry. Installing a workspace screen also installs Frame when the block needs it. You do not assemble that list by hand. You also do not need to install a block in order to use Frame or Pricing on a page of your own.

## How to choose

- The page layout is yours, and shadcn-vue has no pricing card, filter list, or framed panel — install the **component**.
- You want a 工作台 screen that already hangs together — install the **block**, then replace the sample copy and data.
- You want a button, an input, or a dialog — install it from **shadcn-vue**, not from this registry. See [Boundaries with shadcn-vue](/guide/boundaries).
