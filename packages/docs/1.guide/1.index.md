# Quick Start

> Install a component or a block from the @propshow registry.

PropShow Kit is an add-on registry for Shadcn Vue, not a replacement UI library and not an npm package. Components and blocks are published as a **[Shadcn Vue registry](https://www.shadcn-vue.com/docs/registry.html)**, so the `shadcn-vue` CLI copies the source into your project together with everything that entry needs.

## Prerequisites

Your project needs to be set up for **[Shadcn Vue](https://www.shadcn-vue.com/docs/installation.html)** first:

- Tailwind CSS is configured.
- `components.json` exists in your project root — `npx shadcn-vue@latest init` creates it.
- The `cn` helper exists at `@/lib/utils` — the components import it.

## Step 1: Choose an Entry

Browse [Components](/components) when you need one missing piece, such as **[Copy](/components/copy)** or **[Frame](/components/frame)**. Browse [Blocks](/blocks) when you want a ready screen, such as a [workspace](/blocks/workspace) overview, team directory, or settings form (工作台).

The steps below use Copy. A block uses the same command with its own URL.

## Step 2: Install it

Every component page has an **Install** section with the command you need:

```bash
npx shadcn-vue@latest add https://kit.prop.show/r/copy.json
```

The CLI copies the component into your components directory, e.g. `@/components/copy/`, and takes care of its dependencies: `@lucide/vue` and `@vueuse/core` as npm packages, plus the `button` and `tooltip` components it builds on.

Pass several URLs to install several components at once:

```bash
npx shadcn-vue@latest add https://kit.prop.show/r/copy.json https://kit.prop.show/r/status-badge.json
```

### Short Alias (optional)

To avoid repeating the URLs, register PropShow Kit in the `registries` field of your `components.json`:

```json
{
  "registries": {
    "@propshow": "https://kit.prop.show/r/{name}.json"
  }
}
```

Then you can install components by name:

```bash
npx shadcn-vue@latest add @propshow/copy
```

## Step 3: Use the Component

Now you can use the component in your application:

```vue
<script setup lang="ts">
import { Copy } from "@/components/copy";
</script>

<template>
  <div class="p-4">
    <Copy content="Hello, PropShow Kit!" />
  </div>
</template>
```

## Step 4: Customize

The source now lives in your project, so you can modify it to fit. Component pages document props and slots. Block pages document the sample copy, links, and data you should replace.
