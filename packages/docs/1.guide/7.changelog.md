## Latest

### 2026-10-31

- Added [Notification Center](/components/notification-center). It is an inbox panel with unread state, mark read, dismiss, and an empty state. The inbox behavior is original kit code and does not include a third-party notification library.
- Removed 33 marketing blocks ported from SikandarJODD/sv-efferd: call to action, testimonials, integrations, logo cloud, header, hero, and features. Pricing components, workspace blocks, and the other components stay. [Removing the Efferd marketing blocks](/blog/removing-efferd-marketing-blocks) is the longer note.
- The repository README is install-first, with contributing docs, issue and pull request templates, and a security policy. This page is the docs entry for the same changelog.
- The registry is MIT licensed. Adapted components are attributed in `NOTICE` and `THIRD_PARTY.md`.
- The guide covers the `@propshow` registry, components versus blocks, boundaries with shadcn-vue, and common pitfalls.

Earlier dates are in [CHANGELOG.md](https://github.com/prop-show/prop-show-kit/blob/master/CHANGELOG.md).
