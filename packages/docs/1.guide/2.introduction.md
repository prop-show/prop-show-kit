# Introduction

> An add-on registry for Shadcn Vue: components for the gaps, blocks for ready screens.

PropShow Kit is an **add-on registry** for **[Shadcn Vue](https://www.shadcn-vue.com/)**. It is not a replacement UI library and not a fork of the base set. Shadcn Vue stays in charge of the primitives, the tokens, and the CLI. This registry publishes what that set does not ship, in two shapes: **components** that fill a single gap, and **blocks** that install a ready screen. The CLI copies the source into your project.

## Add-on, Not a Fork

- **The base library comes first**: Shadcn Vue provides the primitives, the Tailwind tokens and the registry tooling. PropShow Kit does not replace or preempt any of it.
- **Components fill the gaps**: Frame, pricing, filters, copy, status, and the other [components](/components) are the pieces real projects keep rebuilding.
- **Blocks deliver ready screens**: a [workspace](/blocks/workspace) screen (工作台) arrives as a section you can edit, not as a mock you redraw.
- **The same install path**: components and blocks both arrive through the `shadcn-vue` registry CLI, under the [`@propshow`](/guide/registry) registry.
- **The same conventions**: default styles, tokens and API design follow Shadcn Vue, so an add-on entry drops into an existing project without a second theme.

## Components and blocks

Use a component when the page is already yours and one control is missing. Use a block when you want the screen assembled. The install command does not change:

```bash
npx shadcn-vue@latest add https://kit.prop.show/r/frame.json
npx shadcn-vue@latest add https://kit.prop.show/r/project-overview.json
```

The longer comparison, including every block group, is [Components and blocks](/guide/components-and-blocks). What still belongs to the official registry is [Boundaries with shadcn-vue](/guide/boundaries).

## Design Philosophy

PropShow Kit follows the same design philosophy as Shadcn Vue:

- **Not a Component Library**: It is not an npm package, and it is not a second UI kit that replaces Shadcn Vue. The files live in your codebase, not in `node_modules`.
- **You Own the Code**: You read, change and version the source like any other file in your project.
- **Highly Customizable**: Built on Tailwind CSS, you can modify styles and logic as needed.
- **Unified Style**: Default styles are consistent with Shadcn Vue, seamlessly integrating into your existing projects.

## Why an Add-on?

Projects on Shadcn Vue keep hitting the same holes. The base library does not ship them, and copying a one-off from another codebase rarely matches the tokens you already have. The holes are wider than a single badge:

- **Frame** — panels, notifications, and framed dialogs.
- **Pricing** — a plan card, a responsive set of plans, and a comparison table.
- **Status Badge, Inline Tip, Copy, Filters** — status dots, callouts, clipboard feedback, and a keyboard-friendly filter list.
- **Notification Center** — an inbox panel with unread state, mark read, and an empty state.
- **Blocks** — ready screens on top of those pieces: the [workspace](/blocks/workspace) screens (a project overview, a team directory, and settings).

PropShow Kit fills those gaps so you are not writing the component, or the whole screen, from scratch. Fourteen components and three blocks are on the site today. The [component index](/components) and the [block index](/blocks) are the lists that stay current.

## Key Features

- 🎨 **Shadcn Style**: Maintains visual style and API design consistent with Shadcn Vue.
- 📋 **TypeScript**: Written entirely in TypeScript, providing good type hints.
- 🌙 **Dark Mode**: Perfectly supports light and dark mode switching.
- 🧩 **Independence**: Components and blocks are separate registry entries, so you can install only the ones you need.
