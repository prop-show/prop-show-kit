# Introduction

> PropShow Kit is an add-on registry for Shadcn Vue.

PropShow Kit is an **add-on** to **[Shadcn Vue](https://www.shadcn-vue.com/)**. It is the companion registry for the base library rather than a fork of it: the way an add-on needs the thing it plugs into, PropShow Kit assumes Shadcn Vue is already set up and then adds the pieces it does not ship.

## Add-on, Not a Fork

- **The base library comes first**: Shadcn Vue provides the primitives, the Tailwind tokens and the registry tooling. PropShow Kit does not replace or preempt any of it.
- **The add-on adds what is missing**: on top of those primitives it ships the components the base library leaves out but real projects keep needing.
- **The same install path**: components arrive through the same `shadcn-vue` registry CLI, so the add-on slots in like part of the base library.
- **The same conventions**: default styles, tokens and API design follow Shadcn Vue, so an add-on component drops into an existing project without friction.

## Design Philosophy

PropShow Kit follows the same design philosophy as Shadcn Vue:

- **Not a Component Library**: It is not an npm package. The components live in your codebase, not in `node_modules`.
- **You Own the Code**: You read, change and version the source like any other file in your project.
- **Highly Customizable**: Built on Tailwind CSS, you can modify styles and logic as needed.
- **Unified Style**: Default styles are consistent with Shadcn Vue, seamlessly integrating into your existing projects.

## Why an Add-on?

When developing projects with Shadcn Vue, we often encounter requirements for common components that the base library does not provide, such as:

- **Status Badge**: A badge with a status indicator dot.
- **Inline Tip**: An inline alert box for documentation or tips.
- **Copy**: A button with copy feedback.
- **Filters**: A controlled list of field filters with keyboard navigation.

PropShow Kit aims to fill these gaps, saving you development time by not having to write these components from scratch.

## Key Features

- 🎨 **Shadcn Style**: Maintains visual style and API design consistent with Shadcn Vue.
- 📋 **TypeScript**: Written entirely in TypeScript, providing good type hints.
- 🌙 **Dark Mode**: Perfectly supports light and dark mode switching.
- 🧩 **Independence**: Components are decoupled as much as possible, so you can choose only the components you need.
